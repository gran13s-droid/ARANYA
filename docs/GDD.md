## 1. Elevator Pitch

> **ป่าหิมพานต์กำลังถูก "ราคีม่วง" กัดกิน และผู้พิทักษ์วิญญาณพร้อมวิญญาณหยกคู่กายคือความหวังสุดท้าย**
> MMORPG สไตล์ HD-2D ที่เล่นบนเบราว์เซอร์ได้ทันทีไม่ต้องดาวน์โหลด มีตัวละครพิกเซลบนโลก 3D low-poly ที่มีชีวิต ต่อสู้ด้วยระบบธาตุสี่ธาตุและเครื่องรางจากความเชื่อพื้นบ้าน
> ชวนเพื่อนตั้งปาร์ตี้สี่คน ชำระป่าทีละโซน ชุบชีวิตสัตว์หิมพานต์ และสร้างสำนักของคุณเอง โดยไม่มีของขายที่ทำให้ใครเก่งกว่าใคร

## 2. เสาหลักของการออกแบบ (Design Pillars)

ทุกฟีเจอร์ต้องตอบได้ว่ารองรับเสาหลักข้อไหน ถ้าไม่รองรับข้อใดเลยให้ตัดออก

| # | เสาหลัก | ความหมาย | ตัวอย่างในเกม |
|---|---|---|---|
| 1 | **ชำระ ไม่ใช่ทำลาย** | เป้าหมายของผู้เล่นคือฟื้นฟูป่า ไม่ใช่ฆ่าล้าง | บอสส่วนใหญ่ถูก "ชำระ" กลับเป็นผู้พิทักษ์ ไม่ได้ถูกฆ่า และโลกเปลี่ยนสีตามความคืบหน้า |
| 2 | **เล่นด้วยกันดีกว่า** | ระบบต่าง ๆ ให้รางวัลกับการร่วมมือ | ปฏิกิริยาธาตุข้ามอาชีพ เกจชำระทั้งโซน และ personal loot ที่ไม่ต้องแย่งของ |
| 3 | **ตำนานที่จับต้องได้** | folklore ไทยและอุษาคเนย์ต้องเป็นกลไกเกม ไม่ใช่แค่ฉาก | ตะกรุดและผ้ายันต์เป็นช่องสวมใส่ สายสิญจน์เป็นสกิล ส่วนนาคเป็นบอสที่มีกลไกเฉพาะตัว |
| 4 | **เปิดเล่นได้ทันที** | เข้าเกมผ่านลิงก์ได้ในเวลาไม่ถึง 30 วินาที และเล่นบนมือถือได้ลื่น | โหลดแรกไม่เกิน 25MB, asset ของแต่ละโซนค่อยโหลดทีหลัง, คุมด้วยการแตะได้ |
| 5 | **ยุติธรรมเสมอ** | ทุกอย่างที่มีผลต่อพลังได้มาจากการเล่นเท่านั้น | ร้านค้าขายแค่ของแต่งตัว และ logic สำคัญทั้งหมดอยู่ฝั่ง server |

## 3. เนื้อเรื่องหลัก

### 3.1 โลก

ป่าหิมพานต์คือดินแดนที่อยู่ระหว่างโลกมนุษย์กับสวรรค์ ใจกลางป่าคือ **สระอโนดาต** ซึ่งหล่อเลี้ยง **หยกหัวใจพงไพร** อัญมณีที่ให้กำเนิดสรรพชีวิตในป่า สัตว์หิมพานต์ ทั้งนาค กินนร คชสีห์ และหงส์ อยู่ร่วมกับมนุษย์ในหมู่บ้านชายป่าอย่างสมดุลมานานนับพันปี

### 3.2 ภัยคุกคาม: ราคีม่วง

เมื่อสามสิบปีก่อน มีคนลักลอบทุบ **ผนึกกาลราตรี** ใต้รากไม้ยักษ์ ผนึกนี้เคยกักขัง **อสูรกาลราตรี** สิ่งที่หลุดออกมาไม่ใช่ตัวอสูร แต่เป็นลมหายใจของมัน คือหมอกสีม่วงที่ชาวบ้านเรียกว่า **ราคีม่วง** ราคีม่วงทำให้สิ่งมีชีวิตลืมตัวตน สัตว์หิมพานต์ที่ถูกกัดกินจะดุร้ายและหวงอาณาเขต และป่าจะซีดลงจนเป็นสีเทาม่วง

หยกหัวใจพงไพรแตกออกเป็นเศษเล็กเศษน้อยเพื่อปกป้องตัวเอง เศษแต่ละชิ้นกลายเป็น **วิญญาณหยก** ที่ออกตามหาคนที่ใจตรงกับมัน

### 3.3 ผู้เล่น: ผู้พิทักษ์วิญญาณ

ผู้เล่นเป็นเด็กหนุ่มหรือเด็กสาวจากหมู่บ้าน **บ้านร่มไทร** ซึ่งถูกวิญญาณหยกดวงหนึ่งเลือกในคืนที่ราคีม่วงบุกหมู่บ้าน ผู้เล่นจึงกลายเป็น **ผู้พิทักษ์วิญญาณ** (Spirit Warden) ผู้ที่มองเห็นราคีม่วงและชำระมันได้

**วิญญาณหยกคู่กาย** เป็นหัวใจของตัวตนผู้เล่น ไม่ใช่สัตว์เลี้ยงประดับ

| ด้าน | รายละเอียด |
|---|---|
| ในเนื้อเรื่อง | เป็นเพื่อนคู่คิดที่พูดได้ ค่อย ๆ จำความทรงจำของหยกหัวใจพงไพรได้ทีละน้อย และเปิดเผยปริศนาเรื่องว่าใครเป็นคนทุบผนึก |
| ในการเล่น | ชำระ "ศิลาราคี" ในโลก, ให้บัฟพาสซีฟ, ลบสถานะ "ราคีสะสม" และวิวัฒนาการได้ |
| วิวัฒนาการ | **เมล็ดหยก**: ดวงเปลววิญญาณ (Spirit Flame) ตั้งแต่ Lv 1 → **ยอดหยก**: เปลวหยกสิงร่าง **คันคากหยก** กบวิญญาณจากตำนานพญาคันคาก (หลังชำระบอสโซน 1) → เลือกสายร่าง (หลังชำระบอสโซน 2) → ร่างสมบูรณ์ (หลังชำระบอสโซน 4) |
| รูปลักษณ์ | ทุกร่างหลังจากเมล็ดหยกยังมีเปลววิญญาณลอยอยู่ด้านหลังเสมอ และใบหน้าของเปลวใช้แสดงอารมณ์ใน UI (ดู Art Bible 7.2–7.3, 9.2) |
| สายร่าง (เลือกถาวรต่อตัวละคร) | **หงส์หยก** สายสนับสนุน: ฮีลเล็กน้อยและเพิ่มระยะ buff / **สิงห์หยก** สายโจมตี: เพิ่มดาเมจธาตุหยก / **นาคหยก** สายป้องกัน: โล่ตามรอบเวลา |
| สิ่งที่ห้ามขาย | ร่างและค่าพลังของวิญญาณหยก ร้านค้าขายได้แค่สกินที่เปลี่ยนรูปลักษณ์ (ดูหัวข้อ 10) |

### 3.4 โครงเรื่องตอนเปิดตัว (5 องก์ = 5 โซน)

| องก์ | โซน | เลเวล | แก่นเรื่อง | บอสที่ต้องชำระ |
|---|---|---|---|---|
| 1 | ป่าไทรศักดิ์สิทธิ์ | 1–12 | การตื่นรู้: ได้วิญญาณหยกคู่กายและรู้จักราคีม่วง | นาคต้นไทร (นาคาไทรมูล) |
| 2 | บึงบัวสนธยา | 12–22 | ความสูญเสีย: กินรีผู้ลืมบทเพลงของตัวเอง | ราชินีกินรีไร้เสียง |
| 3 | ผาคชสีห์ | 22–32 | ความหยิ่งทะนง: ฝูงคชสีห์ที่ปฏิเสธความช่วยเหลือ | คชสีห์เผือกเฒ่า |
| 4 | ธารสีทันดร | 32–42 | ความจริง: ผู้ที่ทุบผนึกคือหนึ่งในผู้พิทักษ์รุ่นก่อน | ผู้พิทักษ์ผู้หลงทาง |
| 5 | สระอโนดาตแปดเปื้อน | 42–50 | การเลือก: จะผนึกอสูรซ้ำหรือชำระมัน | อสูรกาลราตรี (เรด 12 คน) |

## 4. Core Loop

### 4.1 ภาพรวม

```
 ┌───────────── สัปดาห์ ─────────────────────────────────────────┐
 │ ┌────────── ชั่วโมง ─────────────────────────────┐             │
 │ │ ┌─── นาที ───┐                                 │  เรดบอส     │
 │ │ │ สู้ → ชำระ │ → เควสต์ / ดันเจี้ยน → ของดรอป   │  กิลด์บอส   │
 │ │ │ → เก็บของ  │ → ปลุกเสกเครื่องราง → ตลาด        │  ฤดูเทศกาล  │
 │ │ └────────────┘                                 │             │
 │ └────────────────────────────────────────────────┘             │
 └────────────────────────────────────────────────────────────────┘
```

### 4.2 รายละเอียดแต่ละวง

| วง | ระยะเวลา | ผู้เล่นทำอะไร | รางวัลที่ได้ | ความรู้สึกที่ต้องการ |
|---|---|---|---|---|
| **นาที** | 30–90 วินาที | สู้กับมอน 1–3 ตัว, สลับธาตุให้ถูกทาง, หลบท่าที่มีพื้นเตือน, ใช้วิญญาณหยกชำระศิลาราคี | EXP, เงิน (เบี้ย), วัตถุดิบ, เกจชำระโซนเพิ่มขึ้น | "เราเล่นเก่งขึ้น" และ "ป่าค่อย ๆ สว่างขึ้น" |
| **ชั่วโมง** | 15–60 นาที | ทำเควสต์เนื้อเรื่องหรือเควสต์ประจำวัน 1 ชุด, ลงดันเจี้ยนปาร์ตี้ 4 คน (15–20 นาที), ปลุกเสกหรือหลอมเครื่องราง, ขายของในตลาด | เครื่องราง, วัตถุดิบหายาก, ความคืบหน้าเนื้อเรื่อง, เบี้ย | "ตัวละครเราแกร่งขึ้นอย่างเห็นได้ชัด" |
| **สัปดาห์** | ทั้งสัปดาห์ | เรดบอสประจำสัปดาห์, เควสต์สำนัก, กิลด์บอส, ภารกิจฤดูเทศกาล, อีเวนต์ "ไทรผลิใบ" ของทั้งโซน | ชุดเครื่องรางระดับสูง, แต้มสำนัก, ของแต่งตัวจากเทศกาล (ฟรี) | "เราเป็นส่วนหนึ่งของชุมชน" |

### 4.3 กติกาการต่อสู้พื้นฐาน

- **รูปแบบ**: ล็อกเป้าแบบ soft lock คือแตะหรือคลิกมอนเพื่อเลือกเป้า แล้วกดสกิลจากแถบลัด 7 ช่อง ออกแบบให้มือถือเล่นได้สะดวก
- **การหลบ**: ท่าใหญ่ของมอนจะมีพื้นเตือน (telegraph) แสดงล่วงหน้า **อย่างน้อย 1.0 วินาที** เพื่อให้ผู้เล่นที่ ping 150ms หลบได้ทันอย่างยุติธรรม
- **ท่าหลบ (ทุกอาชีพมี)**: พุ่งไปตามทิศที่เดิน 4 เมตร ไม่รับดาเมจ 0.25 วิ CD 6 วิ และไม่ใช้ทรัพยากร server ตรวจระยะ, CD และเส้นทางว่าชนสิ่งกีดขวางไหม ส่วนสกิลเคลื่อนที่ของแต่ละอาชีพ (ทะยานพยัคฆ์, ตีลังกาหลบ, หุ่นฟางแทนตัว) ยังคงมีอยู่ และมีผลเพิ่มเติมที่ท่าหลบพื้นฐานไม่มี
- **แถบลัด (ปุ่ม 1–7)**: โจมตี | สกิล 2 | สกิล 3 | สกิล 4 | อัลติเมต | ยา HP | ยามานา ส่วนท่าหลบใช้ปุ่มแยก (PC: Space) และไม่อยู่บนแถบลัด
- **เมาส์ (PC) / แตะ (มือถือ)**: คลิกซ้ายบนพื้นเพื่อเดินไปจุดนั้น (กดค้างเพื่อเดินตามเคอร์เซอร์) คลิกซ้ายบนมอนเพื่อล็อกเป้า (soft lock) แล้วเดินเข้าไปจนถึงระยะฟันและโจมตี 1 ครั้ง กดค้างบนมอนเพื่อตามตีต่อเนื่อง ซึ่งจะต่อคอมโบเอง ปุ่มเดิน (WASD) ยกเลิกการคลิกเดินทันที ปุ่ม Tab ใช้วนเลือกเป้าที่ใกล้ที่สุด
- **หมายเหตุเทคนิค (คลิกเดิน)**: client แปลงจุดที่คลิกเป็นทิศเดินทุก tick (intent เดียวกับปุ่ม แต่ละเอียดกว่า) server ยังใช้กติกาการเดินและการชนเดิม จึงเดินได้เฉพาะที่ปุ่มเดินไปได้ ยังไม่มีการหาเส้นทาง ถ้าติดกำแพงหรือขอบจะหยุดเอง (รอ navmesh F-08)
- **ทรัพยากร**: แต่ละอาชีพใช้ทรัพยากรของตัวเอง 1 ชนิด (ดูหัวข้อ 5) และทุกอาชีพมี HP
- **หมายเหตุเทคนิค**: client ส่งแค่ intent "ใช้สกิล X กับเป้า Y" ส่วนระยะ, cooldown, ทรัพยากร, การโดนหรือไม่โดน และดาเมจ server คำนวณทั้งหมด ข้อมูลสกิลเก็บใน `/shared/data/skills.ts` เพื่อให้ client ใช้ข้อมูลชุดเดียวกันแสดง tooltip และ cooldown

### 4.4 ตัวเลขต่อสู้ชั่วคราว (prototype จาก Step 1.2)

ตัวเลขในตารางนี้ GDD ยังไม่ได้กำหนด จึงตั้งไว้ให้ระบบทำงานได้ก่อน ทุกค่าอยู่ใน `/shared` (`data/skills.ts`, `data/elements.ts`, `constants.ts`) **ปรับได้หลังเล่นทดสอบ** และเมื่อยืนยันแล้วให้ย้ายไปไว้ในหัวข้อของระบบนั้น

| หัวข้อ | ค่าชั่วคราว |

| ค่าพลังนักดาบ Lv 1 | Max HP 500, ATK 50, DEF 30, ธาตุตัวเอง ไฟ |
| ความเร็ววิ่ง | 5 เมตรต่อวินาที |
| คริติคอล | โอกาส 5%, ตัวคูณ ×1.5 |

| Lag compensation | ย้อนตำแหน่งเป้าตาม `100ms + ping/2` สูงสุด 200 ms |

| ยั่ว (ยืนม้าหยก) | มอนในรัศมี 6 เมตรเปลี่ยนเป้ามาที่ผู้ใช้จนหมดเวลาท่ายืน (GDD 5.2) |

## 5. อาชีพ (Classes)

### 5.1 ภาพรวม

ปาร์ตี้มาตรฐานมี 4 คน ซึ่งตรงกับ 4 อาชีพ ดันเจี้ยนออกแบบให้เคลียร์ได้แม้ไม่ครบทุกอาชีพ แต่ถ้าครบจะง่ายที่สุด

| อาชีพ | บทบาทหลัก | ระยะ | ธาตุถนัด | ทรัพยากร | ความยาก |
|---|---|---|---|---|---|
| **นักดาบ** | แทงก์ / ประชิดตัว | ใกล้ | ไฟ, หยก | **ปราณดาบ** (สะสมเมื่อโจมตีหรือโดนตี) | ★★☆ |
| **หมอผี** | ดาเมจเวท / ดีบัฟ / อัญเชิญ | ไกล | มืด, ควัน | **อาคม** (ฟื้นตามเวลา) + **ราคีสะสม** | ★★★ |
| **พรานธนู** | ดาเมจกายภาพ / ควบคุมพื้นที่ | ไกล | ไฟ, ควัน, หยก | **สมาธิ** (ฟื้นเร็วขึ้นเมื่อไม่โดนตี) | ★★☆ |
| **นักพลอง** | ฮีล / ซัพพอร์ต / ตีประชิดได้ | ใกล้–กลาง | หยก | **ลมปราณ** (ฟื้นตามเวลา และได้เพิ่มเมื่อตีโดน) | ★☆☆ |

โครงสกิลของทุกอาชีพ: **สกิลแอคทีฟ 4 + อัลติเมต 1 + พาสซีฟ 1 = 6 สกิล** + ท่าหลบพื้นฐาน (หัวข้อ 4.3) ส่วนการปรับแต่งเพิ่มเติมทำผ่านเครื่องราง (หัวข้อ 7) ไม่ใช่ skill tree เพื่อให้บาลานซ์ง่ายในช่วงเปิดตัว

### 5.3 หมอผี (Shaman)

ผู้ที่ยืมพลังมืดของศัตรูมาใช้ เล่นยากที่สุดแต่ดาเมจสูงที่สุด

**กลไกเฉพาะ: ราคีสะสม**
- สกิลธาตุมืดแต่ละครั้งเพิ่มราคีสะสม 1 ชั้น (สูงสุด 5 ชั้น)
- ทุกชั้นเพิ่มดาเมจ 6% แต่เมื่อครบ 5 ชั้น HP จะลดลง 2% ทุกวินาที

## 6. ระบบธาตุ

### 6.1 สี่ธาตุ

| ธาตุ | สีในพาเลตต์ | แนวคิด | สถานะติดตัว (aura) |
|---|---|---|---|
| 🔥 **ไฟ** | แดงไฟ | พลังทำลาย ความร้อน ระเบิดดาเมจ | เผาไหม้ |
| 🌫️ **ควัน** | ครีมหม่น | มายา การพรางตัว ความอึดอัด | หมอกมัว |
| 💚 **หยก** | หยกเขียว | ชีวิต การปกป้อง การชำระ | รากหยก |
| 🟣 **มืด** | ม่วงมืด | การกัดกิน การดูดกลืน ราคีม่วง | ราคี |

### 6.2 วงจรแพ้ทาง

```
        ควัน ──ชนะ──▶ ไฟ
         ▲              │
        ชนะ            ชนะ
         │              ▼
        มืด ◀──ชนะ── หยก
```

| ผู้ชนะ | ผู้แพ้ | เหตุผลตามตำนาน |
|---|---|---|
| ควัน | ไฟ | ควันอบอวลจนไฟขาดลมหายใจ |
| ไฟ | หยก | ไฟเผาพงไพรและชีวิต |
| หยก | มืด | หยกชำระราคี ซึ่งเป็นแก่นของเรื่อง |
| มืด | ควัน | มายาไร้ความหมายเมื่อไม่มีแสงให้หลอกตา |

คู่ที่ไม่ได้อยู่ติดกันในวงจร (ไฟกับมืด และควันกับหยก) เป็นกลางต่อกัน

### 6.3 ตารางตัวคูณดาเมจ

แถวคือธาตุของผู้โจมตี คอลัมน์คือธาตุของเป้าหมาย

| โจมตี ↓ / เป้า → | ไฟ | ควัน | หยก | มืด |
|---|---|---|---|---|
| **ไฟ** | 0.9 | 0.8 | **1.25** | 1.0 |
| **ควัน** | **1.25** | 0.9 | 1.0 | 0.8 |
| **หยก** | 0.8 | 1.0 | 0.9 | **1.25** |
| **มืด** | 1.0 | **1.25** | 0.8 | 0.9 |

- ธาตุเดียวกันได้ตัวคูณ 0.9 (ต้านทานธาตุตัวเอง)
- ศัตรูที่ติดราคีม่วงทุกตัวมีธาตุรองเป็น "มืด" ถ้ามีสองธาตุ ให้ใช้ค่าเฉลี่ยของตัวคูณทั้งสอง
- ไม่ควรใช้ตัวคูณสูงเกิน 1.25 เพื่อให้อาชีพที่ธาตุไม่ได้เปรียบยังเล่นได้ ไม่โดนบังคับให้ต้องเป็นอาชีพเดียว

### 6.4 ปฏิกิริยาธาตุ (ส่งเสริมการเล่นปาร์ตี้)

เมื่อเป้าหมายติด aura ของธาตุหนึ่งอยู่แล้ว (aura อยู่ได้ 4 วินาที) แล้วโดนอีกธาตุหนึ่ง จะเกิดปฏิกิริยาดังนี้

| ปฏิกิริยา | ธาตุที่ใช้ | ผล | อาชีพที่จับคู่กันได้ดี |
|---|---|---|---|
| **ม่านเพลิง** | ควัน + ไฟ | เมฆควันลุกเป็นไฟ ศัตรูในพื้นที่รับดาเมจ 80% ATK | หมอผี + พรานธนู / นักดาบ |
| **ชำระล้าง** | หยก + มืด | ลบบัฟหรือโล่ของศัตรู และดาเมจระเบิด 120% (ได้ผลรุนแรงกับมอนที่ติดราคี) | นักพลอง + หมอผี |
| **ลับแล** | ควัน + มืด | ศัตรูใช้สกิลไม่ได้ (silence) 2 วิ | หมอผี (คนเดียวทำได้ แต่ CD ยาว) |
| **เพลิงชีวิต** | ไฟ + หยก | ผู้เล่นในรัศมี 5 เมตรได้ฮีล 5% Max HP | นักดาบ + นักพลอง |

ปฏิกิริยาเดียวกันกับเป้าเดียวกันมี cooldown 6 วินาที เพื่อกันการกดวนซ้ำ

### 6.5 สูตรดาเมจ (อ้างอิงฝั่ง server)

```
raw      = ATK × skillCoef
mitigated = raw × (100 / (100 + DEF))
final    = mitigated × elemMult × critMult × reactionMult × defenseMult × random(0.95, 1.05)
final    = max(1, round(final))
```

- `defenseMult` คือตัวคูณจากสถานะของเป้าหมาย ค่าปกติเท่ากับ 1 เช่น บอสขดตัวป้องกัน = 0.2 (หัวข้อ 8.6)
- คำนวณที่ **server เท่านั้น** ค่าคงที่ทั้งหมด (ตารางธาตุ, ตัวคูณคริติคอล) อยู่ใน `/shared/data/elements.ts`
- ใช้ `random()` แบบ seeded ฝั่ง server และบันทึก log เพื่อให้ replay ตรวจสอบย้อนหลังได้

## 7. ระบบเครื่องราง (Talismans)

เครื่องรางเป็นแหล่งพลังหลัก แทนที่ระบบอาวุธและเกราะแบบดั้งเดิม อาวุธในเกมมีไว้เพื่อรูปลักษณ์และกำหนดอาชีพเท่านั้น ค่าพลังมาจากเครื่องรางทั้งหมด

### 7.1 ช่องสวมใส่ (6 ช่อง)

| ช่อง | เครื่องราง | ค่าหลัก (main stat) |
|---|---|---|
| 1 | **ตะกรุด** | ATK / MATK |
| 2 | **ผ้ายันต์** | DEF |
| 3 | **เบี้ยแก้** | Max HP |
| 4 | **ลูกอม** (เครื่องรางทรงกลม) | ทรัพยากรสูงสุดหรืออัตราฟื้น |
| 5 | **สร้อยประคำ** | โบนัสดาเมจธาตุ (เลือก 1 ธาตุ) |
| 6 | **แหวนพิรอด** | คริติคอล / ความเร็วร่าย |

> **แนวทางด้านวัฒนธรรม**: หลีกเลี่ยงการใช้รูปพระพุทธรูปหรือพระเครื่องเป็นไอเทม ใช้เฉพาะเครื่องรางพื้นบ้านทั่วไป และให้ที่ปรึกษาด้านวัฒนธรรมตรวจทุกไอเทมก่อนเผยแพร่

### 7.2 ระดับความหายาก

| ระดับ | สี | ค่ารอง (sub stat) | ปลุกเสกได้สูงสุด | แหล่งที่ได้ |
|---|---|---|---|---|
| ธรรมดา | ครีม | 0 | +5 | มอนทั่วไป |
| ขลัง | เขียวป่า | 1 | +10 | มอนอีลิต, เควสต์ |
| ศักดิ์สิทธิ์ | หยก | 2 | +12 | ดันเจี้ยน |
| อาถรรพ์ | ม่วงมืด | 3 | +15 | เรด, หลอมรวม |
| ตำนาน | ทองวัด | 3 + ผลพิเศษ 1 อย่าง | +15 | บอสเรดครั้งแรก, หลอมรวมระดับสูง |

### 7.3 ปลุกเสก (อัปเกรด)

- ใช้ **ผงว่าน** (วัตถุดิบจากการเล่น) และ **เบี้ย** (เงินในเกม) ระดับละ +1 แต่ละระดับเพิ่ม main stat 6%
- +1 ถึง +6 สำเร็จ 100%
- +7 ขึ้นไปมีโอกาสล้มเหลว แต่ **ไม่มีวันแตก ไม่ลดระดับ และไม่เสียไอเทม**
- ทุกครั้งที่ล้มเหลวจะได้ **แต้มบารมี** เมื่อแต้มเต็ม การปลุกเสกครั้งถัดไปสำเร็จแน่นอน (pity ที่โปร่งใส แสดงตัวเลขให้เห็นตรง ๆ)
- ระดับ +5, +10 และ +15 สุ่มเพิ่มค่ารอง 1 ค่า หรือเสริมค่ารองที่มีอยู่

| ระดับ | โอกาสสำเร็จ | ผงว่าน | เบี้ย | แต้มบารมีที่ได้เมื่อล้มเหลว (เต็ม 100) |
|---|---|---|---|---|
| +1 ถึง +6 | 100% | 2–12 | 100–1,200 | – |
| +7 ถึง +9 | 70% | 15–25 | 2,000–4,000 | 35 |
| +10 ถึง +12 | 50% | 30–45 | 6,000–10,000 | 25 |
| +13 ถึง +15 | 30% | 60–90 | 15,000–25,000 | 15 |

### 7.4 หลอมรวม

| สูตร | วัตถุดิบ | ผลลัพธ์ | หมายเหตุ |
|---|---|---|---|
| **ยกระดับ** | เครื่องรางช่องเดียวกัน ระดับเดียวกัน 3 ชิ้น + เบี้ย | เครื่องรางระดับสูงขึ้น 1 ขั้น 1 ชิ้น | เลือกค่ารองจากชิ้นที่ใส่เข้าไปให้คงไว้ได้ 1 ค่า |
| **ถ่ายพลัง** | เครื่องรางหลัก 1 ชิ้น + ชิ้นที่จะใช้เป็นวัตถุดิบ 1 ชิ้น | ย้ายค่ารอง 1 ค่าจากชิ้นวัตถุดิบมายังชิ้นหลัก (ชิ้นวัตถุดิบหายไป) | ค่าที่ย้ายมาจะเหลือ 80% |
| **ปลุกชุด** | เครื่องราง 1 ชิ้น + "แก่นวิญญาณ" จากบอส | เพิ่มป้ายชุด (set tag) ให้เครื่องราง | ทำให้ของที่ดรอปทั่วไปกลายเป็นส่วนหนึ่งของชุดได้ ลดการต้องฟาร์มซ้ำ |

### 7.5 โบนัสชุด (ชุดของโซน 1)

| ชุด | 2 ชิ้น | 4 ชิ้น | เหมาะกับ |
|---|---|---|---|
| **ชุดเกล็ดนาค** | DEF +10% | เมื่อโดนตี มีโอกาส 15% ได้โล่ 5% Max HP (CD 8 วิ) | นักดาบ |
| **ชุดใบไทรเงิน** | ฮีลแรงขึ้น +8% | ฮีลเกิน HP สูงสุดเปลี่ยนเป็นโล่ได้สูงสุด 10% | นักพลอง |
| **ชุดหิ่งห้อยเพลิง** | ดาเมจธาตุไฟ +10% | สถานะเผาไหม้แพร่ไปยังศัตรูข้าง ๆ 1 ตัว | พรานธนู / นักดาบ |

### 7.6 กติกาการซื้อขายเครื่องราง

- เครื่องรางที่ยังไม่เคยสวมใส่ **ซื้อขายได้**
- เมื่อสวมใส่ครั้งแรกจะ **ผูกวิญญาณ** (bind on equip)
- **ยันต์ปลดพันธะ** ใช้ปลดการผูกได้ 1 ครั้ง ได้จากเควสต์สำนักและคราฟต์เท่านั้น **ไม่ขายในร้านเงินจริง**
- **หมายเหตุเทคนิค**: การสุ่มผลปลุกเสกและหลอมรวมทำที่ server และบันทึกลง Postgres ใน transaction เดียวกับการหักวัตถุดิบ (atomic) แต้มบารมีเก็บไว้กับตัวละคร ไม่ได้เก็บกับไอเทม

#### พฤติกรรมละเอียด: ลูกมอมหลงทาง

มอนตัวแรกที่ผู้เล่นเจอ ทำหน้าที่สอนให้อ่านพื้นเตือนและใช้ท่าหลบ (หัวข้อ 4.3) โดยไม่ลงโทษผู้เล่นใหม่แรงเกินไป

| สถานะ | กติกา |
|---|---|
| ปกติ | ลอยวนในรัศมี 4 เมตรจากจุดเกิด ไม่โจมตีก่อน |
| ถูกโจมตี: ถอย | ถอยห่างจากผู้โจมตี 3 เมตร ใช้เวลา 0.5 วิ (CD 6 วิ ผู้เล่นระยะประชิดจึงตามทัน) |
| ถูกโจมตี: ยิง | รวบรวมพลัง **1.0 วิ** พร้อมพื้นเตือนแบบเส้น (กว้าง 1 เมตร ยาว 8 เมตร) แล้วยิง**ลูกไฟหยก**ตามแนวพื้นเตือน ความเร็ว 6 เมตรต่อวิ ดาเมจ `skillCoef` 1.0 ธาตุหยก CD 4 วิ **ทิศถูกล็อกตั้งแต่เริ่มรวบรวมพลัง** (ไม่ติดตามเป้า) จึงหลบได้ทั้งด้วยการเดินออกด้านข้างและท่าหลบ |
| HP < 30% | หนีออกจากผู้เล่นที่ใกล้ที่สุด 4 วิ ด้วยความเร็ว 1.2 เท่าของผู้เล่น ไม่ยิงระหว่างหนี และกระดิ่งดังเป็นสัญญาณ ถ้าหนีครบ 4 วิแล้วยังไม่ตาย ให้กลับไปทำตามสถานะ "ถูกโจมตี" ต่อ |
| ออกนอกพื้นที่ | ห่างจากจุดเกิดเกิน 15 เมตร: กลับจุดเกิด ฟื้น HP เต็ม และล้างรายชื่อผู้โจมตี |
| ตาย | ถูกชำระ (ราคีหลุดออก ดวงวิญญาณลอยขึ้น) ดรอปผงว่าน |
| จุดเกิด | รอบลานศาลเพียงตา นอกรั้ว (Art Bible 10.9) |

**หมายเหตุเทคนิค**
- ถอย, เวลาพื้นเตือน, การเคลื่อนที่ของลูกไฟ และการตัดสินว่าโดนหรือไม่ คำนวณที่ server ทั้งหมด
- ตรวจการชนของลูกไฟด้วย swept segment ทุก tick เพื่อไม่ให้ลูกไฟทะลุผู้เล่นเมื่อ tick ห่าง
- ตัวเลขในตารางนี้เก็บใน `/shared/data/monsters.ts` client ใช้แค่วาดพื้นเตือนและลูกไฟให้ตรงกับเวลาที่ server ส่งมา

### 8.4 กลไกโลก: ศิลาราคีและเกจชำระโซน

- ทั่วโซนมี **ศิลาราคี** 40 จุด ผู้เล่นใช้วิญญาณหยกชำระได้ (ต้องยืนนิ่ง 3 วินาที และอาจมีมอนมาขวาง)
- ทุกการชำระและการสังหารมอนที่ติดราคีจะเพิ่ม **เกจชำระโซน** ซึ่งเป็นเกจที่ผู้เล่นทั้ง channel แชร์กัน
- เมื่อเกจถึง 100% จะเกิดอีเวนต์ **"ไทรผลิใบ"** 30 นาที: หุบราคีม่วงกลับเป็นสีเขียว ทุกคนได้ EXP +20% และ **วิญญาณไทรยักษ์** (บอสโลกแบบไม่ต้องตั้งปาร์ตี้ ใครตีก็ได้รางวัลตามการมีส่วนร่วม) ปรากฏตัว
- จากนั้นเกจค่อย ๆ ลดลงจนราคีกลับมา ทำให้เกิดวงจรประมาณ 2–3 ครั้งต่อวัน
- **หมายเหตุเทคนิค**: เกจอยู่ใน state ของ room และ sync ข้าม channel ผ่าน Redis pub/sub ส่วนการคำนวณการมีส่วนร่วมทำที่ server

| 2 | ธาตุแห่งพงไพร | ผู้เฒ่าประจำหมู่บ้านสอนเรื่องสี่ธาตุ | ระบบธาตุ, สกิลที่ 2–3 |

### 8.6 บอส: นาคต้นไทร "นาคาไทรมูล"

**ปูมหลัง**: นาคาไทรมูลเป็นพญานาคผู้พิทักษ์รากไทรศักดิ์สิทธิ์มาพันปีจนร่างผสานเป็นหนึ่งเดียวกับต้นไทร ราคีม่วงซึมเข้ามาทางราก ค่อย ๆ เปลี่ยนนาคผู้อ่อนโยนให้กลายเป็นผู้คุ้มกันที่บ้าคลั่ง

| รายการ | รายละเอียด |
|---|---|
| ผู้เล่น | ปาร์ตี้ 4 คน (instance แยก = Colyseus room แยก) |
| เลเวลแนะนำ | 12 |
| เวลาเคลียร์เป้าหมาย | 8–10 นาที (enrage ที่นาทีที่ 12) |
| แนวคิดหลัก | **ธาตุของบอสเปลี่ยนตามเฟส** ผู้เล่นต้องสลับสกิลให้ถูกธาตุ |

#### เฟสและท่าโจมตี

| เฟส | HP | ธาตุบอส | ท่าโจมตี | วิธีรับมือ |
|---|---|---|---|---|
| **1: ผู้พิทักษ์** | 100–70% | หยก (ไฟชนะ) | **หางฟาด**: กวาดเป็นรูปกรวยด้านหลังบอส | อย่ายืนด้านหลังบอส |
| | | | **ฉกเขี้ยว**: ฉกเป้าที่ถูกยั่ว 2 ครั้งติดกัน | แทงก์รับไว้ หรือใช้ท่าหลบ |
| | | | **รากกระหวัด**: รากรัดผู้เล่นแบบสุ่ม 1 คน ตรึงไว้และทำดาเมจต่อเนื่อง | เพื่อนต้องตีรากให้ขาด (รากมี HP แยก) |
| **2: ราคีครอบงำ** | 70–35% | มืด (หยกชนะ) | **พ่นพิษม่วง**: พ่นเป็นเส้นตรงไปยังเป้าที่ถูกยั่ว พื้นเตือน 1.2 วิ | นักดาบใช้ปัดป้องสวนกลับได้ |
| | | | **เรียกนาควิญญาณ**: นาควิญญาณราคี 3 ตัวผุดขึ้นรอบลาน (อยู่กับที่) ถ้าไม่ทำลายภายใน 20 วิจะพุ่งเข้าหาผู้เล่นที่ใกล้ที่สุดแล้วระเบิด | แบ่งคนไปตี ธาตุหยกได้ผลดี (นาควิญญาณเป็นธาตุมืด) |
| | | | **ราคีสะสมหมู่**: ทุกคนติดราคีสะสม 1 ชั้นทุก 10 วิ | นักพลองใช้ปัดเป่าราคี หรือใช้วิญญาณหยก |
| **3: สองจิต** | 35–0% | สลับหยกกับมืดทุก 20 วิ (เกล็ดบนตัวเปลี่ยนสีให้เห็น) | **ทะเลน้ำม่วง**: น้ำราคีท่วมพื้นทุก 45 วิ เป็นเวลา 6 วิ | ปีนขึ้นแท่นรากไม้ 4 แท่น (แท่นละ 1 คน) |
| | | | **ปลดพลังเต็มร่าง**: มงกุฎลุกเป็นไฟตามธาตุขณะนั้น และใช้ท่าของเฟส 1 และ 2 ทั้งหมดถี่ขึ้น | สลับธาตุตามสีเกล็ดและสีมงกุฎ |
| | | | **วงเวทอัญเชิญพญานาค** (อัลติเมต ครั้งเดียวที่ HP 15%): วงเวทเต็มลาน พื้นเตือน 3 วิ | ยืนในวงสายสิญจน์ของนักพลอง หรือยืนบนแท่นราก |

**ธาตุของท่าโจมตี**: ทุกท่าเป็นธาตุเดียวกับบอสขณะนั้น ในเฟส 3 ท่าของเฟส 1 และ 2 จึงเปลี่ยนธาตุตามการสลับทุก 20 วิ และภาพของท่าสลับสีตามไปด้วย เช่น พ่นพิษม่วงตอนบอสเป็นธาตุหยกจะกลายเป็น **"ลำแสงเทพนาค"** สีหยก ผู้เล่นจึงอ่านธาตุของท่าที่กำลังมาได้จากสีของพื้นเตือนและ VFX (Art Bible 7.4, 8.5) ยกเว้นนาควิญญาณที่ถูกเรียกออกมา ซึ่งเป็นธาตุมืดเสมอ

**การเปลี่ยนเฟส: ขดตัวป้องกัน** (เมื่อ HP ลดถึง 70% และ 35%)

| ช่วง | เวลา | กติกา |
|---|---|---|
| ขดตัว | 4 วิ | บอสขดตัวเป็นวงในบ่อ รับดาเมจเพียง 20% (`defenseMult` = 0.2) ไม่โจมตี และท่าที่กำลังร่ายอยู่ถูกยกเลิกพร้อมลบพื้นเตือน |
| เซ | 3 วิ | บอสคลายตัวแล้วเซ รับดาเมจปกติและไม่โจมตี เป็นช่วงให้ผู้เล่นใช้สกิลแรงหรืออัลติเมต |
| เข้าเฟสใหม่ | – | ธาตุบอสเปลี่ยนตามเฟสใหม่ตอนจบช่วงเซ และเริ่มนับเวลาของท่าในเฟสนั้นใหม่ |

- ดาเมจส่วนที่เกินเกณฑ์ HP ยังคิดตามปกติ บอสจึงไม่ล็อก HP ไว้ที่ 70% หรือ 35%
- ตัวจับเวลา enrage เดินต่อระหว่างขดตัวและเซ
- อัลติเมตวงเวทอัญเชิญพญานาคที่ HP 15% ไม่มีการขดตัวก่อน

**หมายเหตุเทคนิค**: ธาตุของท่าถูกล็อกที่ server **ตอนเริ่มพื้นเตือน** ถ้าบอสสลับธาตุระหว่างที่ท่ากำลังร่าย ท่านั้นยังเป็นธาตุเดิมจนจบ client ใช้ค่าธาตุที่ server ส่งมากับ event เริ่มท่าเพื่อเลือก LUT ไม่คำนวณเอง ภาพกับดาเมจจึงตรงกันเสมอ

#### ตอนจบ

เมื่อ HP ถึง 0 บอสไม่ตาย ผู้เล่นทั้ง 4 คนต้องยืนในวงแสงหยกพร้อมกัน 5 วินาทีเพื่อ **ชำระ** นาคาไทรมูล ราคีจะหลุดออกจากร่าง แล้วนาคตื่นขึ้น ขอบคุณผู้เล่น และมอบเกล็ดของตนให้ ฉากนี้เน้นเสาหลักข้อ 1 "ชำระ ไม่ใช่ทำลาย"

#### รางวัล (personal loot สุ่มที่ server)

| รางวัล | เงื่อนไข | หมายเหตุ |
|---|---|---|
| เกล็ดหยกนาค | เคลียร์ครั้งแรก | ใช้วิวัฒนาการวิญญาณหยกเป็นร่างยอดหยก |
| เครื่องรางชุดเกล็ดนาค (ศักดิ์สิทธิ์) | โอกาส 35% ต่อคนต่อรอบ | ซื้อขายได้จนกว่าจะสวมใส่ |
| แก่นวิญญาณนาค | 1–2 ชิ้นทุกรอบ | ใช้ในสูตรปลุกชุด |
| ผงว่าน และเบี้ย | ทุกรอบ | |
| ฉายา "ผู้ชำระรากไทร" | เคลียร์ครั้งแรก | ใช้แสดงผลอย่างเดียว ไม่มีค่าพลัง |

ได้รางวัลเต็มวันละ 3 รอบ หลังจากนั้นเหลือแค่ผงว่านและเบี้ย เพื่อลดการฟาร์มแบบบอต

### 9.3 ตลาด ("ตลาดน้ำอรัญญา")

| หัวข้อ | กติกา |

| ระยะเวลาวางขาย | 48 ชั่วโมง ถ้าขายไม่ออก ของคืนทางไปรษณีย์ในเกม |

> **หมายเหตุเทคนิค (ตลาดและเทรด)**: ทุกคำสั่งซื้อขายมี idempotency key และใช้ `SELECT ... FOR UPDATE` ล็อกแถวไอเทมและกระเป๋าเงิน การซื้อจากตลาดทำผ่าน service แยกที่ไม่ผูกกับ zone room เพื่อให้ซื้อได้จากทุกโซน

### 9.4 การสื่อสาร

- ช่องแชท: รอบตัว / โซน / ปาร์ตี้ / สำนัก / กระซิบ / หาปาร์ตี้

## 10. Monetization แบบไม่ Pay-to-Win

### 10.1 หลักการ

1. **เงินจริงซื้อพลังไม่ได้ ไม่ว่าทางตรงหรือทางอ้อม**
2. **ไม่มีกาชาหรือกล่องสุ่ม** ทุกอย่างซื้อแบบเห็นของก่อนจ่าย
3. **เงินพรีเมียมแลกเป็นเบี้ยไม่ได้** และของที่ซื้อด้วยเงินจริงซื้อขายในตลาดไม่ได้ (ปิดช่องทางซื้อพลังทางอ้อม)
4. ทุกอย่างที่ขายต้องดูดี **เกมจึงต้องสวยตั้งแต่ไม่จ่ายเงิน** ถ้าคนที่ไม่จ่ายดูจืด เกมจะสร้างแรงกดดันให้ต้องจ่าย

### 10.2 สกุลเงิน

| สกุลเงิน | ได้มาจาก | ใช้กับ |
|---|---|---|
| **เบี้ย** | การเล่น | ทุกอย่างในระบบเกม, ตลาด |
| **มุกจันทร์** (พรีเมียม) | ซื้อด้วยเงินจริง และได้เล็กน้อยจาก Season Pass ฟรี | ร้านแต่งตัวเท่านั้น |

### 10.3 ขายอะไรและไม่ขายอะไร

| ✅ ขาย | ❌ ไม่ขาย |
|---|---|
| ชุดและสกินตัวละคร | เครื่องรางหรือวัตถุดิบปลุกเสก |
| สกินวิญญาณหยก (เปลี่ยนรูปลักษณ์ ร่างและค่าพลังเหมือนเดิม) | ตัวเพิ่มโอกาสปลุกเสกสำเร็จ หรือแต้มบารมี |
| สกินอาวุธ (ไม่มีค่าพลัง) | ตัวเพิ่ม EXP หรือเบี้ย |
| อีโมต, ท่าทาง, ฉายาพิเศษ | ยันต์ปลดพันธะ |
| ของตกแต่งศาลาสำนักแบบพรีเมียม | ข้ามดันเจี้ยนหรือตั๋วเข้าเพิ่ม |
| สกินพาหนะ (พาหนะพื้นฐานได้ฟรีจากเควสต์) | พาหนะที่เร็วกว่า |
| ช่องตัวละครเพิ่ม (ฟรี 3 ช่อง) | ช่องกระเป๋า (ขยายได้จากการเล่นเท่านั้น) |
| เปลี่ยนชื่อ, เปลี่ยนหน้าตา | ตัวชุบชีวิตแบบไม่มีเงื่อนไข |

### 10.4 Season Pass "ฤดูเทศกาล"

- 1 ฤดูยาว 8 สัปดาห์ ผูกกับเทศกาลไทยและอุษาคเนย์ เช่น สงกรานต์, ลอยกระทง, บุญบั้งไฟ, ไหลเรือไฟ
- **สายฟรี**: ของแต่งตัวตามธีม 15 ชิ้น, มุกจันทร์ 300, ฉายาประจำฤดู
- **สายพรีเมียม (฿199)**: ของแต่งตัว 40 ชิ้น รวมชุดหลักของฤดู และคืนมุกจันทร์ 800 (พอซื้อพาสฤดูถัดไปได้ถ้าเล่นจนจบ)
- รางวัลทุกชิ้นในทั้งสองสายเป็น **ของแต่งตัวเท่านั้น**
- เลเวลของพาสได้จากการเล่นปกติ และ **ไม่ขายเลเวลพาส** (กันการจ่ายเพื่อข้าม)

| แพ็ก | ราคา | มุกจันทร์ | โบนัส |
|---|---|---|---|
| ถุงเล็ก | ฿35 | 350 | – |
| ถุงกลาง | ฿99 | 1,000 | +50 |
| ถุงใหญ่ | ฿299 | 3,000 | +300 |

### 10.6 ความรับผิดชอบต่อผู้เล่น

- ผู้เล่นอายุต่ำกว่า 18 ปีถูกจำกัดยอดซื้อต่อเดือน (ค่าเริ่มต้น ฿1,000) โดยผู้ปกครองตั้งค่าเองได้
- แสดงยอดใช้จ่ายสะสมให้ผู้เล่นเห็นในหน้าโปรไฟล์
- ไม่ใช้นาฬิกานับถอยหลังกดดันในร้าน ยกเว้นของเทศกาลที่หมดเวลาจริง
- ของแต่งตัวที่หมดฤดูแล้วจะกลับมาขายใหม่ในฤดูถัด ๆ ไป ไม่ทำให้ใครตกรถถาวร
