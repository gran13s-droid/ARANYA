## 1. ทิศทางภาพ (Visual Direction)

**สรุปหนึ่งประโยค**: *ตัวละครพิกเซลชิบิที่อบอุ่น ยืนอยู่ในป่าโบราณ 3D ที่มีแสงลอดใบไม้ พลังวิญญาณสีหยกเรืองแสงตัดกับราคีสีม่วง*

| ชั้นภาพ | ทำด้วยอะไร | กฎหลัก |
|---|---|---|
| **ตัวละคร มอน บอส** | สไปรต์พิกเซลแบบ billboard | ใช้พาเลตต์ 15 สีเคร่งครัด, 32px = 1 เมตร, sampling แบบ nearest |
| **ฉาก** | โมเดล 3D low-poly + texture พิกเซล | texture ใช้พาเลตต์ ส่วนแสง หมอก และเงาให้ engine จัดการ |
| **VFX** | สไปรต์พิกเซลเป็นแกน + engine เพิ่มแสงเรือง (additive + bloom) | แกนของเอฟเฟกต์ใช้พาเลตต์ แสงเรืองรอบ ๆ engine สร้างให้ |
| **UI** | กรอบพิกเซลลายไทย + ตัวอักษรแบบ vector | ขยายเป็นจำนวนเต็มเท่า, ห้ามอบข้อความลงในรูป |

**สีหลักของอัตลักษณ์เกม** (ตาม UI & Effect concept): Emerald Green = `FOREST`, Jade Cyan = `JADE` และ `SPIRIT`, Antique Gold = `GOLD` และ **สีศัตรู** = `CURSE`

**กฎข้อยกเว้น**: สิ่งที่ engine สร้างขึ้นเอง ได้แก่ แสง, เงาใต้ตัว (blob shadow), หมอก, bloom, การ fade ด้วย alpha และ color grading **ไม่ต้องอยู่ในพาเลตต์** แต่พิกเซลใน texture และสไปรต์ทุกชิ้นต้องอยู่ในพาเลตต์

## 2. แปลง concept เป็นงานในเกม

concept sheet ทั้ง 5 แผ่นใช้เป็น **เป้าหมายด้านอารมณ์ รูปทรง และสี** ไม่ใช่ asset ที่ใช้ได้ตรง ๆ เพราะเป็นภาพวาดแบบ painterly ที่มีไล่สีหลายร้อยเฉด และสัดส่วนเปลี่ยนไปในแต่ละแผ่น ตารางนี้สรุปว่าต้องปรับอะไรบ้าง

| จาก concept | ปัญหา | กฎในเกม |
|---|---|---|
| แถบ MP สีน้ำเงิน, ขวดยาสีฟ้า, Spirit Flame สีน้ำเงิน | สีน้ำเงินไม่มีในพาเลตต์ | MP ใช้ `JADE`, ยา HP ใช้ `FIRE`, ยาฟื้นทรัพยากรใช้ `JADE` และสีของ Spirit Flame ผูกกับธาตุ (ดูหัวข้อ 8.2) |
| แสงเรืองแบบนุ่มที่วาดลงในภาพ | ใช้กับพิกเซลอาร์ตไม่ได้ และกิน fill-rate บนมือถือ | วาดเป็นแกนพิกเซลแข็ง แล้วให้ engine ใส่ bloom (ปิดได้ใน quality ต่ำ) |
| แถบสกิลอยู่มุมขวาบน | เล่นไม่ถนัด เพราะนิ้วโป้งบนมือถืออยู่ด้านล่าง | PC: กลางล่าง / มือถือ: ขวาล่างแบบรัศมีรอบปุ่มโจมตี |
| รายละเอียดชุด Hero (หัวเข็มขัด, ผ้าพันข้อมือ, ลายผ้า) | เล็กกว่า 1px เมื่อย่อลงเหลือ 64px | เหลือ **จุดจำ 4 อย่าง**: ผ้าพันคอหยก, หางม้า, ดาบคู่ และเข็มขัดทอง |
| ลายก้นหอยและยันต์บนตัวกบ | ลายมากเกินจนอ่านไม่ออกที่ 32px | ก้นหอยใหญ่ 1 วงที่หลัง + 2 วงที่ขา |
| ระย้าทองที่มงกุฎนาค | ละเอียดเกินไป | มงกุฎทรงเปลวไฟอ่านออกจาก silhouette ส่วนระย้าเหลือ 2 เส้น เส้นละ 1–2px และแกว่งตามแอนิเมชัน idle |
| ป้ายภาษาอังกฤษ (Idle, Attack, Skill 1) | เกมต้องรองรับหลายภาษา | ข้อความทั้งหมดอยู่ในไฟล์ i18n และห้ามอบลงในรูป |
| สัดส่วนตัวละครต่างกันในแต่ละแผ่น | ไม่สม่ำเสมอ | ล็อกสัดส่วนตามหัวข้อ 4.2 และใช้ model sheet ที่ Art Lead อนุมัติเป็นต้นฉบับเดียว |

> **หมายเหตุลิขสิทธิ์**: ถ้า concept sheet ถูกสร้างด้วย AI ให้ใช้เป็นภาพอ้างอิงภายในเท่านั้น asset ที่ใช้จริงในเกมต้องให้ทีมวาดหรือปั้นใหม่ เพื่อให้สไตล์คงที่และถือลิขสิทธิ์ได้ชัดเจน (หลายประเทศยังไม่รับรองลิขสิทธิ์ของภาพที่ AI สร้าง)

### 2.1 ข้อกำหนดสำหรับการสร้าง concept ครั้งต่อไป

concept หลายแผ่นมีปัญหาเดิมซ้ำกัน (ภาพที่ 6–19) ให้แนบข้อกำหนดนี้ไปกับ brief หรือ prompt ทุกครั้ง

| ห้าม | ใช้แทน |
|---|---|
| สีชมพู, สีฟ้าหรือน้ำเงิน (ผ้า, ผ้าใบ, ดอกบัว, ขวดยา) | `FIRE`, `GOLD`, `JADE`, `CREAM` |
| สีม่วงบนสิ่งที่ไม่ใช่ราคี (ดอกไม้เรืองแสง, ไอเทม, แสงประดับ) | `SPIRIT` หรือ `CREAM` เพราะม่วงสงวนไว้ให้ศัตรูและราคีเท่านั้น |
| โคมหินญี่ปุ่นที่มีหลังคาเจดีย์เล็ก | เสาหัวเม็ดทรงบัวตูม, ตะคันดินเผา, โคมแขวนไม้ |
| ชายคางอนแบบจีน, ซุ้มแบบโทริอิ, หลังคาทรงเจดีย์จีน | หลังคาจั่วชัน ปั้นลมปลายเป็นตัวเหงา, ซุ้มไม้แบบไทย |
| พระพุทธรูป, พระเครื่อง, เจดีย์ (ทั้งเป็นวัตถุและเป็นทรงของเสาหรือยอด) | เศษหยก, ตุ๊กตาช้างม้า, หลักหิน, เสาหัวเม็ด |
| ท้องฟ้า, ดวงจันทร์, ฉากหลังไกลในภาพที่ใช้อ้างอิงฉากเกม | มุมกล้องก้ม 35° ตามเกมจริง (หัวข้อ 10.1) |
| คำแนะนำให้ใช้กล้อง orthographic 45° | perspective FOV 30° ก้ม 35° และ yaw ล็อก (หัวข้อ 10.1) |
| เส้นทางที่ต้องกระโดดข้ามช่อง | บันได ทางลาด จุดไต่ หรือสะพาน เพราะผู้เล่นกระโดดไม่ได้ (หัวข้อ 13 ข้อ 4) |
| นาคที่มีขาหรือกรงเล็บ, แผงหนามรอบตัวแบบมังกร | นาคเป็นงูไม่มีขา มีหงอนตามสันหลังและมงกุฎ (หัวข้อ 7.4) |
| ธงหรือป้ายแบบตราประจำตระกูลยุโรป | ตุงแบบล้านนา หรือผ้าแพร ในสีของพาเลตต์ |
| ม่วงสว่างทั้งจอในพื้นที่ราคี | พื้นและหมอกมืด (`INK`, `PURPLE_DEEP`) และ `CURSE` ที่สว่างไม่เกิน 15% ของจอ ตามลำดับความสว่างในหัวข้อ 10.13 |

## 3. พาเลตต์ 15 สี

### 3.1 ตารางสี

ลำดับในตารางคือ index ในไฟล์พาเลตต์ **ห้ามสลับลำดับ** เพราะ shader สำหรับสลับสี (palette swap) อ้างอิงตาม index

| # | ชื่อ | Hex | กลุ่ม | บทบาท |
|---|---|---|---|---|
| 01 | `INK` | `#141B1A` | ฐาน | outline และเงาเข้มที่สุด (ดำอมเขียว ห้ามใช้ดำสนิท `#000`) |
| 02 | `FOREST_DEEP` | `#1E3A2E` | ป่า | เงาของใบไม้, พื้นหลังของแผง UI |
| 03 | `FOREST` | `#2E6040` | ป่า | ใบไม้หลัก (Emerald) |
| 04 | `MOSS` | `#6F9A45` | ป่า | ไฮไลต์ใบไม้, หญ้า, ระดับความหายาก "ขลัง" |
| 05 | `JADE_DEEP` | `#17695F` | หยก | เงาของสิ่งที่เป็นหยก, ผ้าพันคอ |
| 06 | `JADE` | `#2DB597` | หยก | ธาตุหยก, แถบ MP, ระดับ "ศักดิ์สิทธิ์" |
| 07 | `SPIRIT` | `#8DF2D6` | หยก | **ใช้กับสิ่งที่เรืองแสงเท่านั้น**: วิญญาณ, เวทฝั่งผู้เล่น, สิ่งที่โต้ตอบได้ |
| 08 | `STONE` | `#6B7466` | กลาง | หินโบราณ, ซากปรักหักพัง, ธาตุควัน |
| 09 | `BARK` | `#4A3024` | ดิน | เปลือกไม้, เงาผิว, ผม |
| 10 | `EARTH` | `#A0663F` | ดิน | ผิว, ดิน, หนัง |
| 11 | `GOLD` | `#C99A3E` | ทอง | ทองวัด, กรอบ UI, เกราะนาค, ระดับ "ตำนาน" |
| 12 | `CREAM` | `#F2E5C4` | แสง | ไฮไลต์สูงสุด, ข้อความ UI, ผ้า, แกนของเอฟเฟกต์ |
| 13 | `FIRE` | `#CE3E2A` | อันตราย | ธาตุไฟ, แถบ HP, ดาเมจ |
| 14 | `PURPLE_DEEP` | `#3B2149` | ราคี | เงาของราคี, ออร่าคำสาป |
| 15 | `CURSE` | `#B048C8` | ราคี | **สีของศัตรูเท่านั้น**: ราคีม่วง, ตานาค, ระดับ "อาถรรพ์" |

### 3.2 Ramp ที่อนุญาต (เข้มไปสว่าง)

ไล่แสงเงาได้เฉพาะตาม ramp เหล่านี้ เพื่อให้สีสม่ำเสมอทั้งเกม และใช้ hue shift (เงาอมเย็น ไฮไลต์อมอุ่น)

| Ramp | ลำดับสี | ใช้กับ |
|---|---|---|
| ป่า | `INK` → `FOREST_DEEP` → `FOREST` → `MOSS` → `CREAM` | ต้นไม้, หญ้า, เสื้อผ้าสีเขียว |
| หยก | `INK` → `JADE_DEEP` → `JADE` → `SPIRIT` → `CREAM` | วิญญาณหยก, เวท, ผ้าพันคอ (ผ้าที่ไม่เรืองแสงหยุดที่ `JADE`) |
| ทอง | `BARK` → `EARTH` → `GOLD` → `CREAM` | เครื่องประดับ, เกราะนาค, กรอบ UI |
| ผิว | `BARK` → `EARTH` → `GOLD` (ไฮไลต์จุดเล็กเท่านั้น) | ผิวของมนุษย์ |
| หิน | `INK` → `FOREST_DEEP` → `STONE` → `CREAM` | ซากปรักหักพัง, ทางเดิน |
| ไฟ | `BARK` → `FIRE` → `GOLD` → `CREAM` | ธาตุไฟ, ผีโขมด |
| ราคี | `INK` → `PURPLE_DEEP` → `CURSE` → `CREAM` | ราคีม่วง, คำสาป |

### 3.3 กฎการใช้สีตามกลุ่มงาน

| กลุ่ม | ใช้ได้ | จำกัด | ห้ามใช้ |
|---|---|---|---|
| **ฉาก** | ป่า, หิน, ดิน, ทอง (ศาลหรือวัดร้าง) | `SPIRIT` ใช้เฉพาะจุดที่โต้ตอบได้ (ศิลาราคีที่ชำระแล้ว, ศาล), `CURSE` ใช้เฉพาะในพื้นที่ที่ติดราคี | `FIRE` (สงวนไว้ให้ความหมายว่าอันตรายหรือดาเมจ) **ยกเว้นในเขตปลอดภัยที่ไม่มีการต่อสู้** เช่น บ้านร่มไทร ใช้เป็นสีผ้าแพร ธง และผ้าใบได้ไม่เกิน 10% ของจอ |
| **ตัวผู้เล่น** | ทุก ramp ยกเว้นราคี | `SPIRIT` ได้เฉพาะชิ้นที่เรืองแสง (ใบดาบตอนใช้สกิล) | `CURSE`, `PURPLE_DEEP` ห้ามใช้ในชุดหรือสกินที่ขายในร้าน เพราะผู้เล่นต้องแยกพวกเดียวกันกับศัตรูได้ทันที |
| **มอนและบอส** | ทุก ramp | ศัตรูที่ติดราคีต้องมี `CURSE` อย่างน้อย 10% ของพื้นที่ silhouette | `SPIRIT` (ยกเว้นตอนถูกชำระแล้ว) |
| **VFX** | ramp ของธาตุนั้น + แกนเป็น `CREAM` | VFX ของผู้เล่นคนอื่นแสดงที่ opacity 40% | VFX ที่ไม่มีธาตุใช้ `FIRE` ไม่ได้ |
| **UI** | `INK`, `FOREST_DEEP` (พื้นหลัง), `GOLD` (กรอบ), `CREAM` (ข้อความ) | สีสถานะ: HP = `FIRE`, MP = `JADE`, EXP = `GOLD`, วิญญาณ = `SPIRIT` | ห้ามใช้สีนอกพาเลตต์ แม้แต่ข้อความ |

**สีความหมายที่ล็อกถาวรทั้งเกม** (ตรงกับ GDD):

| ความหมาย | สี |
|---|---|
| ธาตุ ไฟ / ควัน / หยก / มืด | `FIRE` / `STONE` + `CREAM` / `JADE` / `CURSE` |
| ระดับ ธรรมดา / ขลัง / ศักดิ์สิทธิ์ / อาถรรพ์ / ตำนาน | `CREAM` / `MOSS` / `JADE` / `CURSE` / `GOLD` |
| พื้นเตือนท่าศัตรู (telegraph) | ขอบ `CREAM` กะพริบ + พื้นสี `FIRE` alpha 35% |

> **ผู้เล่นตาบอดสี**: `FIRE` กับ `FOREST` เป็นคู่แดง-เขียว ผู้เล่นที่ตาบอดสีแดง-เขียวจะแยกไม่ออก ดังนั้นพื้นเตือนต้องมี**ขอบสว่างที่กะพริบ**เสมอ ห้ามพึ่งสีอย่างเดียว และแถบ HP กับ MP ต้องแยกกันด้วยตำแหน่งและไอคอนด้วย

## 4. ขนาดสไปรต์และกริด

### 4.1 กฎกลาง

- **PPU = 32**: 32 พิกเซลเท่ากับ 1 เมตรในโลก ทุกสไปรต์ในเกมใช้ค่าเดียวกัน **ห้ามย่อหรือขยายสไปรต์ในเกม** (ห้ามผสมความละเอียด)
- **จุดหมุน (pivot)**: กึ่งกลางของเท้าหรือฐาน (bottom-center) ส่วนสิ่งที่ลอยอยู่ (Spirit Flame) ใช้ pivot ที่จุดกึ่งกลางของเงาบนพื้น

- **ห้ามวาดสิ่งที่ไม่สมมาตรซึ่งจะผิดเมื่อกลับภาพ** เช่น ตัวอักษร หรือตราที่อยู่แค่ข้างเดียว ถ้าจำเป็นต้องมี ให้วาดทิศ W แยก

### 5.1 กฎกลาง

- เล่นแอนิเมชันที่ฐาน **12 fps (83ms ต่อเฟรม)** และกำหนดให้แต่ละเฟรมค้างนานต่างกันได้ ทำให้ทั้งเครื่อง 60fps และ 30fps เห็นจังหวะเดียวกัน
- **เฟรมกระทบ (impact frame)** ต้องตรงกับ `impactMs` ของสกิลนั้นใน `/shared/data/skills.ts` เพราะ server ตัดสินการโดนตามเวลานั้น ถ้าภาพกับ server ไม่ตรงกัน ผู้เล่นจะรู้สึกว่าโดนก่อนเห็นท่า

## 6. Outline แสงเงา และ Dithering

### 6.1 Outline

| งาน | กฎ |
|---|---|
| ตัวละคร มอน บอส | เส้นขอบ **1px** สี `INK` รอบ silhouette ด้านนอก บอสก็ใช้ 1px เท่ากัน **ห้ามใช้เส้นหนาขึ้นเพราะตัวใหญ่** |
| เส้นด้านใน | ใช้สีเข้มสุดของ ramp ในบริเวณนั้น (selective outline หรือ sel-out) ไม่ใช้ `INK` เพื่อไม่ให้ภาพดูหนักและสกปรก |
| ขอบด้านที่รับแสง (ซ้ายบน) | เปลี่ยนเส้นขอบเป็นสีเข้มของ ramp ในบริเวณนั้นได้ ทำให้ตัวดูกลมขึ้น |
| VFX | **ไม่มี outline** ใช้แกนสว่างที่ขอบนุ่ม (ฟุ้ง) แทน |
| UI | ขอบนอก 1px `INK` + ขอบใน 1px `GOLD` |
| ฉาก 3D | ไม่มี outline ส่วนสิ่งที่โต้ตอบได้ให้ engine ใส่ขอบ `GOLD` เมื่อเมาส์ชี้หรือเข้าใกล้ |

### 6.2 แสงเงา: แสงมาจากซ้ายบน

- **ทิศแสงหลัก**: ซ้ายบน และค่อนมาด้านหน้า (ประมาณ 45° ในแนวราบ, 50° ในแนวดิ่ง) **directional light ใน engine ต้องตั้งทิศเดียวกัน** เพื่อให้เงาของฉาก 3D สอดคล้องกับสไปรต์
- ลงเงาด้วย ramp **3 ระดับ** (เงา, สีหลัก, ไฮไลต์) + จุดไฮไลต์สูงสุดไม่เกิน 5% ของพื้นที่
- **ปัญหาการกลับภาพ**: เมื่อ mirror E เป็น W แสงจะกลายเป็นมาจากขวาบน กฎคือ **ลงเงาแบบแสงจากบนเป็นหลัก** ให้ความต่างซ้าย-ขวาไม่เกิน 1 ระดับ ramp เพื่อให้ภาพที่กลับแล้วยังดูถูก
- **เงาบนพื้น**: ให้ engine วาดวงรีใต้ตัว (blob shadow) **ห้ามวาดเงาลงในสไปรต์** ส่วนสิ่งที่ลอยอยู่ เงาจะเล็กลงตามความสูง
- **ห้าม**: ลงเงาแบบหมอน (pillow shading ที่มืดรอบขอบทุกด้าน), เส้นสีซ้อนเป็นแถบ (banding) และเส้นที่ขั้นบันไดไม่สม่ำเสมอ (เส้นต้องเดินตามจังหวะ 1:1, 1:2, 2:1 หรือ 1:3)

### 6.3 Dithering

| ใช้ได้ | ห้ามใช้ |
|---|---|
| ลายตาราง 50% (checker 2×2) **ระหว่างสีที่อยู่ติดกันใน ramp เท่านั้น** | dither แบบสุ่มหรือมีลายคล้าย noise |
| texture ฉาก เช่น หิน ดิน หรือหมอกบนพื้น | สไปรต์ที่เล็กกว่า 64px |
| พื้นผิวใหญ่ของบอส เช่น เกล็ดท้อง | ใบหน้า |
| พื้นหลังแผง UI (`INK` กับ `FOREST_DEEP`) | สิ่งที่เคลื่อนไหว เพราะลายจะกะพริบ (shimmer) |
| | VFX (ใช้ alpha ของ engine แทน) |

**Anti-aliasing ด้วยมือ**: ใช้ได้เฉพาะเส้นโค้งของสไปรต์ขนาด 96px ขึ้นไป โดยใช้สีกลางของ ramp 1 พิกเซลต่อขั้น

### 7.5 อีก 3 อาชีพ (brief สำหรับทำ concept)

ทุกอาชีพใช้โครงร่าง สัดส่วน และกริดเฟรมเดียวกับ Hero และต้องผ่าน **silhouette test แบบเรียง 4 อาชีพ** คือเทดำทั้ง 4 ตัวเรียงกันแล้วต้องบอกได้ทันทีว่าตัวไหนอาชีพอะไร

| อาชีพ | จุดจำใน silhouette | สีหลัก | อาวุธ / อุปกรณ์ | บุคลิกและท่ายืน | VFX หลัก |
|---|---|---|---|---|---|
| **นักดาบ** (Hero) | หางม้าสูง + ดาบคู่ + ชายผ้าพันคอ | `CREAM` / `FOREST_DEEP` / `JADE` | ดาบสั้นคู่ | มุ่งมั่น ย่อเข่า พร้อมพุ่ง | รอยฟันหยกและไฟ |
| **หมอผี** | ผ้าโพกหัวทรงสูงมีเชือกห้อย 2 เส้น + ย่ามสะพาย + หุ่นฟางเล็กห้อยเอว | `BARK` / `FOREST_DEEP` / `CREAM` และเชือกสายสิญจน์ `FIRE` | ไม้เท้าเถาวัลย์บิดเกลียว ห้อยตะกรุด 3 ดอก | ลึกลับ หลังงอเล็กน้อย ตาครึ่งปิด | ควันและคำสาป (LUT "มืดฝั่งผู้เล่น" ในหัวข้อ 8.2) |
| **พรานธนู** | หมวกงอบปีกกว้าง (silhouette ชัดที่สุดในกลุ่ม) + ธนูยาวเลยหัว + กระบอกลูกธนูไม้ไผ่ | `MOSS` / `EARTH` / `CREAM` และผ้าขาวม้าลายตาราง `FOREST` + `CREAM` ที่เอว | ธนูไม้ไผ่ | สงบ ระวังตัว ยืนเฉียง | ลูกศรไฟ, ควัน, เถาวัลย์ |
| **นักพลอง** | พลองยาวกว่าตัว 1.5 เท่า + ผ้าประเจียดแดงที่ต้นแขน + ผมสั้นเกรียน | `CREAM` / `JADE` / `GOLD` และผ้าประเจียด `FIRE` | พลองไม้ปลายหุ้มทอง | ร่าเริง ยืนตรง หมุนพลองในท่า idle | ดอกบัว, วงสายสิญจน์, ละอองหยก |

- **ห้ามใช้ `PURPLE_DEEP` หรือ `CURSE` ในชุดของหมอผี** แม้อาชีพนี้จะใช้ธาตุมืด ให้ความมืดอยู่ใน VFX เท่านั้น ผู้เล่นจะได้ไม่สับสนกับศัตรู
- ลายตารางของผ้าขาวม้า: แต่ละช่องอย่างน้อย 2×2 px ถ้าเล็กกว่านี้จะกะพริบเวลาเคลื่อนไหว
- **รูปร่าง 2 แบบ (ชาย/หญิง)** ตาม GDD 3.3: ใช้ฐานร่างร่วมกัน 2 แบบ ท่าเคลื่อนที่ทั่วไป (idle, walk, run, หลบ, โดนตี, ตาย, อีโมต รวม 46 เฟรม) ใช้ร่วมกันทุกอาชีพ ส่วนท่าที่ผูกกับอาวุธ (โจมตี, ร่าย, อัลติเมต รวม 30 เฟรม) แยกตามอาชีพ
  - **รวมเฟรมตัวเปล่าทั้งหมด**: (46 × 3 ทิศ × 2 ร่าง) + (30 × 3 ทิศ × 2 ร่าง × 4 อาชีพ) ≈ **1,000 เฟรม** ปริมาณนี้คือเหตุผลหลักที่แนะนำ pipeline ปั้น 3D แล้ว render เป็นพิกเซล (หัวข้อ 11.1)

| จุดจำ | ใบหน้าเกิดจากเปลือกไม้และราก, ดวงตาเป็นโพรงแสง `SPIRIT`, รากอากาศห้อยเหมือนเครา และผ้าแพรสามสี (`FIRE`, `GOLD`, `JADE`) พันรอบลำต้นตามความเชื่อเรื่องต้นไม้ใหญ่ |
| แอนิเมชัน | ผุดขึ้นจากดิน, idle ไหวกิ่ง, ฟาดราก (พื้นที่วงกลม), พายุใบไม้ (รูปกรวย), เรียกสปอร์ฮีลตัวเอง (เป็นเป้าที่ผู้เล่นต้องทำลาย), พ่ายแพ้แล้วผลิดอกและสลายเป็นใบไม้ |
| ความอ่านง่าย | ผู้เล่นตีพร้อมกันได้ถึง 80 คน ดังนั้นแต่ละคนเห็นแค่ตัวเลขดาเมจของตัวเอง + แฟลชบนตัวบอส ส่วน hit VFX ของคนอื่นไม่ต้องแสดง |

### 7.7 มอนสเตอร์ปกติ: ลูกมอมหลงทาง (M-01)

อ้างอิง concept ภาพที่ 16 เป็นมอนตัวแรกที่ผู้เล่นเจอ และเป็นมอนของ vertical slice (M0) ข้อมูลตาม GDD 8.3 คือ เลเวล 1–3, ธาตุหยก, ไม่โจมตีก่อน, วิ่งหนีเมื่อ HP ต่ำ และดรอปผงว่าน

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | **silhouette ชัดมาก**: หัวโตมีจุกผมทรงมวยกับใบไม้, ตัวเล็ก, หางวิญญาณเรียว และกระดิ่งทอง ซึ่งย่อเป็น 48 px แล้วยังอ่านออก มีภาพหน้า ข้าง และหลังครบ ตรงกับการวาด 3 ทิศ (S, E, N) พอดี |
| ✔ ใช้ได้ | ตา `CURSE` เรืองแสงบอกว่าติดราคี ซึ่งถูกตามกฎสีสงวน (ศัตรูเท่านั้น) และกระดิ่งทองใช้เป็นเสียงเตือนได้ (ดูด้านล่าง) |
| ❌ ธาตุ | **ลูกไฟและคลื่นพลังเป็นสีม่วง** แต่ GDD กำหนดให้เป็นธาตุหยก สีของท่าโจมตีต้องบอกธาตุ (หัวข้อ 8.2) จึงต้องใช้ ramp หยก มิฉะนั้นผู้เล่นจะเรียนรู้ระบบแพ้ทางผิดตั้งแต่มอนตัวแรก |
| ❌ ม่วงเกิน | **เปลวไฟม่วงลอยรอบตัว** ให้เอาออก เพราะหน้าตาจะซ้ำกับผีโขมด (ดวงไฟลอย) และเป็น particle ที่ต้องจ่ายต่อมอนทุกตัว ส่วนม่วงบนตัวให้เหลือแค่ตา ผ้าพันคอ และปลายหาง ส่วนอื่นใช้ `BARK` / `EARTH` / `MOSS` / `CREAM` |
| ⚠ เกมเพลย์ | concept ให้เป็นมอน**โจมตีระยะไกลที่ถอยหนีตลอด** ซึ่งขัดกับ GDD ที่ให้ "ไม่โจมตีก่อน" และไม่เหมาะกับมอนตัวแรกที่นักดาบระยะประชิดต้องไล่ตาม จึงผสานเป็นสเปกด้านล่าง |
| ⚠ ท่า | มอนเล็กไม่มีท่าพิเศษ (หัวข้อ 5.4) จึงตัด "หมุนตัวสร้างคลื่นพลัง" ออก และ "Alert" ไม่ต้องวาดเฟรม ให้ใช้ตาที่สว่างขึ้นด้วย palette swap |
| ⚠ จุดเกิด | concept ให้เกิดในดงรากไทรและหุบราคี (เลเวล 8–12) แต่ GDD เป็นเลเวล 1–3 จึงอยู่**รอบลานศาลเพียงตานอกรั้ว** (หัวข้อ 10.9) |
| ⚠ ดรอป | แก่นโขมดเป็นของผีโขมด และ "Spirit Essence" ไม่มีใน GDD ให้ดรอปผงว่านตาม GDD อย่างเดียว |
| ⚠ ชื่ออังกฤษ | **"Lost Little Mom" แปลผิด** เพราะ Mom แปลว่าแม่ ต้องตั้งชื่อใหม่ในไฟล์ i18n (ดูหัวข้อ 13) |
| ⚠ ภาพจำลองในเกม | โคมทางขวาเป็นโคมหินญี่ปุ่นอีกครั้ง (หัวข้อ 2.1) และการ์ดข้อมูลมี "ประเภท: วิญญาณ" ซึ่งไม่มีระบบนี้ใน GDD ให้ UI แสดงไอคอนธาตุแทน |

**พฤติกรรม**: ผสาน GDD กับข้อเสนอ "วิญญาณขี้กลัว" ใน concept แล้ว (✔ ซิงก์ลง GDD 8.3 "พฤติกรรมละเอียด: ลูกมอมหลงทาง" ซึ่งเป็นที่เก็บตัวเลขทั้งหมด) สรุปคือ ไม่โจมตีก่อน → ถูกตีแล้วถอย 3 เมตร → พื้นเตือนแบบเส้น 1.0 วิ → ยิงลูกไฟหยกที่ช้าและไม่ติดตามเป้า → HP ต่ำกว่า 30% หนีพร้อมเสียงกระดิ่ง

## 8. VFX

### 8.1 กฎกลาง

- **โครงสร้าง**: แกนเป็นสไปรต์พิกเซล (ไม่มี outline) + engine เพิ่มแสงเรืองแบบ additive และ bloom
- **วาด VFX แบบ indexed 4 ช่อง** (เงา / กลาง / สว่าง / แกน) แล้วใช้ shader สลับเป็นสีของแต่ละธาตุ: **วาดครั้งเดียว ได้ทุกธาตุ**
- **ความอ่านง่ายใน MMO**: VFX ของผู้เล่นคนอื่นแสดงที่ opacity 40% และไม่มี screen shake ส่วน **พื้นเตือนของศัตรูวาดทับ VFX ทุกชนิดเสมอ**
- **งบบนมือถือ**: particle บนจอพร้อมกันไม่เกิน 300 และพื้นที่ additive ที่ซ้อนกันไม่เกิน 2.5 เท่าของพื้นที่จอ ส่วน quality ต่ำลด particle ลง 50% และปิด bloom

### 8.2 LUT สีตามธาตุ

| ธาตุ / ประเภท | ช่อง 0 (เงา) | ช่อง 1 (กลาง) | ช่อง 2 (สว่าง) | ช่อง 3 (แกน) |
|---|---|---|---|---|
| หยก (ค่าเริ่มต้นของผู้เล่น) | `JADE_DEEP` | `JADE` | `SPIRIT` | `CREAM` |
| ไฟ | `BARK` | `FIRE` | `GOLD` | `CREAM` |
| มืด / ราคี (ศัตรู) | `PURPLE_DEEP` | `CURSE` | `CURSE` | `CREAM` |
| มืด (ฝั่งผู้เล่น: หมอผี) | `PURPLE_DEEP` | `CURSE` | `SPIRIT` | `CREAM` |
| ควัน | `FOREST_DEEP` | `STONE` | `CREAM` | `CREAM` |
| ทอง (ตำนาน, อัลติเมต) | `EARTH` | `GOLD` | `CREAM` | `CREAM` |

Spirit Flame ทั้ง 4 สีใน concept แปลงเป็น **หยก / ไฟ / มืด / ทอง** ตามตารางนี้ ส่วนสีน้ำเงินตัดออก

**มืดฝั่งผู้เล่น** มีช่องสว่างเป็น `SPIRIT` ทำให้คำสาปของหมอผีมีขอบเป็นสีหยก ผู้เล่นจึงแยกออกทันทีว่าเป็นพลังของฝ่ายตัวเอง ไม่ใช่ท่าของศัตรู นี่คือข้อยกเว้นเดียวของกฎ "`CURSE` ใช้กับศัตรูเท่านั้น"

## 9. UI และลวดลายไทย

### 9.1 กริดและการขยาย

- ความละเอียดออกแบบ **640 × 360** แล้วขยายเป็นจำนวนเต็มเท่า (×2 = 720p, ×3 = 1080p, ×4 = 1440p) โดยใช้ `floor(min(w/640, h/360))`
- UI ยึดกับขอบจอ (anchor) จอที่สัดส่วนต่างออกไปจะมีพื้นที่ว่างตรงกลาง ไม่ใช่ขอบดำ
- **ตัวอักษรเป็น vector font ไม่ใช่ฟอนต์พิกเซล** เพราะภาษาไทยมีสระบน สระล่าง และวรรณยุกต์ซ้อนกัน ฟอนต์พิกเซลขนาดเล็กอ่านไม่ออก
  - หัวข้อ: **Chonburi** (ไทย, มีหัว, ดูคลาสสิก)
  - เนื้อหา: **Noto Sans Thai Looped**
  - ตัวเลข HUD และดาเมจ: ฟอนต์ bitmap ตัวเลขที่วาดเอง
  - ทั้งหมดเป็นสัญญาอนุญาต OFL และ subset ให้เหลือไฟล์ละไม่เกิน 150KB
- ปุ่มบนมือถือมีพื้นที่แตะอย่างน้อย 44 × 44 pt

### 9.3 ลวดลายไทยและวิธีลดทอนเป็นพิกเซล

**หลักการลดทอน 4 ขั้น**

1. **หา silhouette หลัก** ลายไทยเต็มรูปมีเส้นซ้อนหลายชั้น ให้เก็บแค่เส้นโครงที่เห็นจากระยะไกล
2. **ลดจำนวนเส้นให้เหลือ 1–3 เส้น** เช่น กนกสามตัวลดเหลือ "ม้วนโคน, ตัวลำ, ปลายเปลว"
3. **ล็อกให้ตรงกริด** ทุกเส้นต้องเดินจังหวะ 1:1, 1:2 หรือ 2:1 และความหนาเส้น 1px (2px เมื่อลายใหญ่กว่า 32px)
4. **ลงสีแค่ 2–3 สี**: `GOLD` (ลาย) + `CREAM` (ไฮไลต์) + `INK` (เส้นขอบ) ห้ามไล่สี

| ลาย | ความหมาย / ที่มา | ใช้ที่ไหนใน UI | ขนาดพิกเซล | ลดทอนอย่างไร |
|---|---|---|---|---|
| **กนก** | ลายเปลวไฟหรือยอดพืช เป็นพื้นฐานของลายไทย | มุมกรอบแผง, ปลายมุมช่องสกิล, เส้นคั่นหัวข้อ | 8×8 (มุม 9-slice), 12×12 (มุมใหญ่) | เหลือ "ม้วนโคน 3×3 + ลำโค้ง + ปลายแหลม 1px" ม้วนไปทางเดียว และ mirror ใช้กับมุมตรงข้าม |
| **ประจำยาม** | ลายดอกสี่กลีบ ใช้คั่นหรือเป็นจุดกลาง | ป้ายเลเวล, ทรงช่องสกิล, จุดกลางวงเวท, bullet | 5×5 (bullet), 9×9 (ป้าย) | กลีบ 4 กลีบชี้ 4 ทิศ + เกสรกลาง 1px ตัดใบแทรกออก |
| **ดอกบัว** | ความบริสุทธิ์ สอดคล้องกับธีม "ชำระ" | โลโก้หัวข้อ, ไอคอนฮีลหรือชำระ, กลางวงเวท | 11×8 (หัวข้อ), 16×16 (ไอคอน) | มองจากด้านหน้า กลีบหน้า 1 + ข้าง 2 + ฐาน 1 เส้น สำหรับ 16px เพิ่มกลีบหลังอีก 2 กลีบ |
| **ก้นหอย** | ลายวนของวิญญาณและน้ำ | Spirit Flame, กบ, โล่, ปลายเส้นคั่น | 5×5, 7×7 | เป็นเกลียว 1.5 รอบ เส้น 1px ปลายด้านนอกตัดแหลม |

### 9.4 ข้อควรระวังด้านวัฒนธรรม

- **ห้ามใช้อักขระขอมหรือยันต์จริง** บนตัวละคร ไอเทม หรือ UI เพราะมีความหมายทางความเชื่อ ให้ใช้ลายก้นหอยและลายเส้นที่ออกแบบขึ้นใหม่ที่ "ดูเหมือนยันต์" แทน
- ห้ามใช้พระพุทธรูป พระเครื่อง หรือรูปทรงเจดีย์เป็นไอคอนหรือ VFX ส่วนดอกบัวและประจำยามใช้ได้ เพราะเป็นลายมงคลทั่วไป
- มงกุฎนาคทรงเปลวไฟที่คล้ายชฎาใช้ได้ แต่ห้ามใช้กับตัวละครที่เป็นตัวตลกหรือศัตรูชั้นต่ำ
- งานที่ใช้ลายไทยทุกชิ้นต้องผ่านที่ปรึกษาด้านวัฒนธรรมก่อนเผยแพร่

- ขนาด **24 × 24 px** พื้นที่ปลอดภัย 22 × 22, outline 1px สี `INK`, แสงจากซ้ายบน และใช้พาเลตต์ 15 สี

## 10. ฉาก 3D (Environment)

### 10.1 กล้อง

| ค่า | กำหนด |
|---|---|
| ประเภท | perspective, FOV แนวตั้ง 30° (แคบ ให้ภาพใกล้เคียง isometric แต่ยังมีมิติ) |
| มุมก้ม | 35° (ตรงกับมุมที่ใช้วาดสไปรต์) |
| ระยะ / ซูม | กำหนดเป็น **pixel scale จำนวนเต็ม** ไม่ใช่ระยะเป็นเมตร เพื่อให้พิกเซลของสไปรต์คมเสมอ ตอนสำรวจใช้ ×3 ที่ 1080p (เห็นกว้างประมาณ 20 เมตร) ส่วนลานบอสใช้ ×2 (ดูหัวข้อ 10.7) |
| การหมุน | **ล็อก yaw ไว้ต่อโซน ห้ามหมุนอิสระ** เพราะสไปรต์มีแค่ 4 ทิศ |
| Post-process | tilt-shift DOF (PC เท่านั้น), bloom, color grading LUT แยกตามพื้นที่ และ vignette อ่อน ๆ |
| ท้องฟ้าและขอบฟ้า | **มองไม่เห็นในเกม** เพราะกล้องก้ม 35° ขอบบนของภาพจึงยังต่ำกว่าเส้นขอบฟ้า 20° ไม่ต้องทำ skybox หรือฉากหลังภูเขาไกล ให้ใช้ distance fog สีตามพื้นที่ที่ขอบบนจอแทน (ยกเว้นใน cutscene) |
| Landmark สูง | กล้องมองจากด้านบน ต้นไม้สูงจึงเด่นด้วย**ทรงพุ่มและเงาบนพื้น**มากกว่าความสูง เมื่อผู้เล่นยืนใต้ต้น ยอดจะหลุดเลยขอบบนจอ ให้ landmark อ่านออกจากทรงพุ่มเมื่อมองจากทางทิศใต้ของมัน และมีไอคอนบนมินิแมปด้วย |

### 10.4 แสง บรรยากาศ และราคี

- directional light 1 ดวง **จากซ้ายบน (ทิศเดียวกับสไปรต์)** + แสงรอบทิศแบบ hemispheric
- bake แสงสะสมไว้ล่วงหน้าเป็น lightmap ส่วน dynamic point light ใช้ได้ PC ไม่เกิน 4 ดวง มือถือไม่เกิน 1 ดวง (ใช้กับวิญญาณหยกของผู้เล่นเอง)
- พืชใช้ thin instances + alpha test (**ห้าม alpha blend**) และขยับด้วย vertex shader สำหรับลม
- **วัตถุที่บังผู้เล่น** เช่น เรือนยอด ราก หรือหลังคา ที่อยู่ระหว่างกล้องกับผู้เล่น ให้จางหายด้วย screen-door dither ใน shader ภายใน 0.2 วิ ข้อนี้เป็นข้อยกเว้นของกฎ dithering ในหัวข้อ 6.3 เพราะเป็นเอฟเฟกต์ของ engine ไม่ได้วาดลงใน texture
- **รอบวันในเกม** (ข้อเสนอ):
  - 1 วันในเกมยาว 120 นาทีจริง แบ่งเป็น กลางวัน 70 / เย็น (golden hour) 10 / กลางคืน 30 / เช้า 10
  - server เป็นคนกำหนดเวลา ทุกคนใน channel จึงเห็นเวลาเดียวกัน และอีเวนต์กลางคืน (หิ่งห้อยทองใน GDD 8.2) ผูกกับเวลานี้ได้
  - เปลี่ยนแค่**มุมเงย**และสีของแสงกับ LUT 4 ชุด ส่วน**ทิศของแสงในแนวราบคงที่จากซ้ายบนเสมอ** เพื่อให้เงาของฉากตรงกับแสงที่อบไว้ในสไปรต์ เช่น เที่ยงวันมุมเงยสูงเงาสั้น ตอนเย็นมุมเงยต่ำเงายาว ไม่ต้องทำ texture ชุดใหม่
  - โคมไฟและหน้าต่างใช้ emissive ที่สว่างขึ้นตอนกลางคืน ไม่ใช้ dynamic light
- **ราคีระดับโซน**: ส่งค่าเกจชำระโซน (GDD 8.4) เป็นตัวเลข 0–1 เข้า shader ของฉาก
  - ค่าต่ำ: หญ้าและใบไม้ไล่สีไปทางเทาม่วง และหมอกม่วงหนาขึ้น
  - ค่าเต็ม 1: สีกลับเป็นปกติ และมีดอกไม้ผลิ
  - ทำด้วย LUT ทั้งหมด **ไม่ต้องทำ asset สองชุด**
- **ศิลาราคี**
  - ก่อนชำระ: ผลึก `CURSE` เรืองแสง + decal หมอกรัศมี 3 เมตร
  - หลังชำระ: หินมีมอสและดอกไม้เล็ก มีประกาย `SPIRIT` จาง ๆ 10 วิแล้วดับ

### 10.6 ผลตรวจ concept ฉากโซน 1 (ภาพที่ 7)

concept นำเสนอแต่ละพื้นที่เป็นเกาะลอยแบบ diorama แต่ในเกมทุกพื้นที่ต่อเนื่องเป็นผืนเดียว และใช้หมอกปิดขอบโซน ส่วน texture แบบภาพวาดต้องแปลงเป็นพิกเซล 32 px ต่อเมตรตามหัวข้อ 10.2 ภาพรวมของอารมณ์และองค์ประกอบใช้ได้ดี แต่มีจุดที่ต้องแก้ดังนี้

| พื้นที่ | ผล | ใช้ต่อได้ | ต้องแก้ |
|---|---|---|---|

**กล้อง**: ตอบข้อเสนอใน concept ที่แนะนำให้ใช้กล้อง Fixed หรือ Orthographic

- **ใช้ Fixed camera** กล้องไม่ตามผู้เล่น ตั้งไว้ที่ศูนย์กลางลาน มองจากทิศใต้ไปทิศเหนือ (ฝั่งทางเข้า)
- **ไม่เปลี่ยนเป็น orthographic** แต่ใช้ perspective FOV 30° เหมือนทั้งเกม เพราะใกล้เคียง orthographic อยู่แล้ว และทำให้แสง หมอก และขนาดสไปรต์ตรงกับฉากอื่น ไม่ต้องสลับระบบกล้องระหว่างฉาก ส่วน tilt-shift ให้เบลอเฉพาะนอกขอบลาน
- **Safe camera bounds**:
  - พื้นที่ที่ต้องอยู่ในจอเสมอคือสี่เหลี่ยม 28 × 28 เมตร (ลาน 24 เมตร + ขอบข้างละ 2 เมตร) โดยคิดจาก viewport ที่หักพื้นที่ HUD ด้านบนและแถบสกิลด้านล่างออกแล้ว
  - ให้โค้ดเลือก **pixel scale จำนวนเต็มที่ใหญ่ที่สุด** ที่ทำให้พื้นที่นี้อยู่ในจอทั้งหมด
  - ใส่ debug overlay แสดงกรอบนี้ไว้ทดสอบ เพราะหัวนาคที่สูงประมาณ 6 เมตรจะกินพื้นที่ด้านบนของจอเพิ่ม

**ผลตรวจ concept ฉบับละเอียด (ภาพที่ 14)**

concept ฉบับนี้แก้ปัญหาส่วนใหญ่ของภาพที่ 7 แล้ว เลย์เอาต์ใกล้เคียงสเปกด้านบนมาก

| ผล | รายการ |
|---|---|
| ✔ แก้แล้ว | **แท่น 4 แท่นเป็นแท่นหินยกพื้นที่มีบันได** ไม่ใช่เสาตะเกียงแล้ว และวางตามแนวทแยงถูกต้อง |
| ✔ ใช้ได้ | นาคผุดจากบ่อกลาง, ลำแสงจากเพดานลงบ่อ, รากไทรคลุมเพดานและผนัง, บันไดทางเข้าทางทิศใต้ (ฝั่งกล้อง), น้ำตกด้านข้าง, ลายวงทองบนพื้น และมุมมองที่เห็นลานกับแท่นครบในจอเดียว |
| ⚠ แท่น | **กระถางไฟวางอยู่กลางยอดแท่น** ทำให้ผู้เล่นยืนไม่ได้ ให้ย้ายไปมุมด้านนอก แท่นในภาพเป็นทรงพีระมิด 3 ชั้น ซึ่งสูงและกว้างเกินไป ให้เหลือสูง 1.5 เมตรและฐานไม่เกิน 4 × 4 เมตร เพราะแท่น 2 แท่นด้านหน้าอยู่ฝั่งกล้องและจะบังผู้เล่นที่ยืนข้างหลัง ส่วนบันไดของแท่นด้านหน้าหันออกด้านข้าง ให้หันเข้าหาศูนย์กลาง เพราะผู้เล่นมีเวลาวิ่งขึ้นแท่นแค่ 3 วิก่อนน้ำท่วม |

| ❌ ไม่เข้าธีม | **ธงสีม่วงแบบตราประจำตระกูลยุโรป** ให้เปลี่ยนเป็น**ตุง** (ธงแขวนแบบล้านนา) สี `CREAM` / `GOLD` / `FOREST` ที่ซีดและเปื้อนราคี ตุงเข้ากับศาสนสถานใต้ต้นไม้ และความเปื้อนก็เปลี่ยนตามเฟสด้วย LUT ได้ |
| ⚠ ตัวบอส | **นาคในภาพเป็นวิญญาณสีหยกโปร่งแสงที่ตาเรือง `SPIRIT`** ภาพนี้ผู้เล่นจะอ่านว่าเป็นฝ่ายดี จึงตรงกับ**ร่างหลังถูกชำระในฉากจบ** ไม่ใช่ร่างตอนต่อสู้ ร่างต่อสู้ใช้ตามหัวข้อ 7.4 คือเกล็ดทึบ ไล่จาก `INK` ถึง `JADE` ตา `CURSE` และมงกุฎทอง |

| ⚠ ราคี | ผลึกม่วงและหมอกม่วงให้อยู่**นอกวงลาน** (เกินรัศมี 12 เมตร) เท่านั้น ในลานใช้แค่เส้นเลือดราคีบนรากและพื้นสี `PURPLE_DEEP` ที่ลามเข้ามาตามเฟส ซึ่งต้องมืดกว่าพื้นเตือนเสมอ |
| ⚠ ซ้ำ | โคมบนเสาสองข้างบันไดทางเข้าเป็นทรงโคมญี่ปุ่น ให้เปลี่ยนเป็นเสาหัวเม็ดกับตะคัน (หัวข้อ 2.1) |
| ⚠ เทคนิค | concept เสนอกล้อง orthographic 45° ให้ใช้ fixed camera แบบ perspective ตามที่กำหนดไว้ด้านบน ส่วน "Global Illumination" ให้ใช้ lightmap ที่ bake ไว้ + emissive (หัวข้อ 10.4) เพราะ GI แบบเรียลไทม์เกินงบมือถือ |

**กลไกที่รับมาจาก Gameplay Design ใน concept**

| ข้อใน concept | สเปก |
|---|---|
| 1. นาคผุดจากบ่อ (intro) | ฉากสั้น 4–5 วิ ทำด้วยการเลื่อนสไปรต์ขึ้นจากผิวน้ำพร้อม clip ที่ระดับน้ำ + ท่าเปลี่ยนเฟส (หัวข้อ 5.5) + VFX น้ำกระจาย **ไม่ต้องวาดเฟรมใหม่** ระหว่างนี้ server ให้บอสโจมตีไม่ได้และโดนดาเมจไม่ได้ และข้ามฉากได้หลังจากเคลียร์ครั้งแรก |
| 2. แท่นเป็นกลไกผนึก | **ข้อเสนอ**: ระหว่างทะเลน้ำม่วง แท่นที่มีผู้เล่นยืนจะเรืองขอบ `GOLD` ถ้าครบ 4 แท่นพร้อมกัน บอสจะเซ 4 วิหลังน้ำลด เป็นรางวัลของปาร์ตี้ที่ไม่มีใครตาย (ต้องเพิ่มลง GDD 8.6 ดูหัวข้อ 13) |
| 3. บ่อเปลี่ยนสีตามสถานะบอส | น้ำและบัวในบ่อสลับ LUT ร่วมกับ dynamic light ที่บ่อ: เฟส 1 `JADE` / เฟส 2 `CURSE` / เฟส 3 สลับทุก 20 วิตามธาตุบอส / ฉากชำระเป็น `SPIRIT` + `GOLD` ทำให้ผู้เล่นดูธาตุของบอสจากบ่อได้อีกทางหนึ่ง |
| 4. ราคีลามเข้าพื้น | พื้นสี `PURPLE_DEEP` ลามจากขอบลานเข้าหาบ่อทีละเฟสผ่าน LUT ร่วมกับเส้นเลือดบนราก และหายไปหลังชำระ |
| 5. สู้ด้วย Hero + Frog Spirit | **ขัดกับ GDD 3.3** เพราะผู้เล่นได้คันคากหยกหลังชำระนาคตัวนี้ ระหว่างสู้คู่หูจึงยังเป็นเปลววิญญาณ (เมล็ดหยก) ซึ่งช่วยล้างราคีสะสมจากท่า "ราคีสะสมหมู่" ส่วนคันคากหยกให้ปรากฏตัวครั้งแรก**ในฉากจบ** ตอนที่นาคมอบเกล็ดให้และเปลววิญญาณสิงร่างกบ |

### 10.8 บ้านร่มไทร (hub และเขตปลอดภัย)

อ้างอิง concept ภาพที่ 8 ทิศในตารางยึดตามกล้อง คือทิศเหนืออยู่ด้านบนของจอ

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | ต้นไทรเป็นจุดนำสายตา (visual anchor) พร้อมผ้าแพรพันโคนต้นและโคมห้อยจากกิ่ง, ลานหินที่มีลายวงกลม, เรือนยกพื้น, ลำธารด้านหน้าพร้อมทางเดินไม้, หอสังเกตการณ์ที่ช่วยบอกทิศ และแสงโคมยามค่ำ |
| ⚠ สี | ผ้าใบและธงสีน้ำเงินหรือม่วงน้ำเงินใช้ไม่ได้ (น้ำเงินไม่มีในพาเลตต์ และม่วงสงวนไว้ให้ราคี) ให้เปลี่ยนเป็น `JADE_DEEP` / `GOLD` / `CREAM` ส่วนผ้าแดงยังใช้ได้ตามข้อยกเว้นเขตปลอดภัยในหัวข้อ 3.3 และบัวชมพูในลำธารให้เปลี่ยนเป็นบัวขาว |
| ⚠ สถาปัตยกรรม | **ซุ้มประตูทางขวามีหน้าตาคล้ายโทริอิของญี่ปุ่นหรือป้ายจีน และหลังคาหอสังเกตการณ์เป็นทรงเจดีย์จีน** ให้เปลี่ยนเป็นซุ้มประตูไม้แบบไทย และหลังคาจั่วชัน ส่วนเรือนให้เห็นจุดจำของเรือนไทยชัด ๆ คือ หลังคาจั่วชันมีปั้นลมปลายเป็นตัวเหงา, ใต้ถุนโล่งที่มีแคร่และโอ่ง และชานเรือน หลีกเลี่ยงชายคาที่งอนแบบจีน |
| ⚠ ประสิทธิภาพ | hub คือจุดที่มีผู้เล่นหนาแน่นที่สุด (สูงสุดประมาณ 80 คนต่อ channel) ตะเกียงหลายสิบดวงในภาพต้องเป็น emissive + baked ทั้งหมด ห้ามใช้ dynamic light ธงราวให้ขยับด้วย vertex shader และเรือนยอดไทรต้องจางหายเมื่อผู้เล่นเดินเข้าใต้ต้น (หัวข้อ 10.4) |

**ตำแหน่งจุดสำคัญ** (ปรับจากรายการ Gameplay Placement ใน concept)

| ตำแหน่ง | จุด | หมายเหตุ |
|---|---|---|
| ใต้ หน้าลานตลาด | **จุดเกิด (spawn)** | หันหน้าขึ้นเหนือ ผู้เล่นจึงเห็นต้นไทรเต็มตาตั้งแต่เข้าเกม ตามข้อแนะนำใน concept |
| เหนือ กลางลาน | ต้นไทร + **ศาลเจ้าที่โคนไทร** | ใช้เป็น**จุดผูกการเกิดใหม่และจุดวาร์ป**แทน "Save Point" ใน concept เพราะเกม MMO ให้ server เซฟข้อมูลอัตโนมัติอยู่แล้ว (ROADMAP 3.1) ผู้เล่นจึงไม่ต้องมีจุดเซฟ |
| ข้างลานกลาง | ป้ายประกาศ | หาปาร์ตี้, รับสมัครสำนัก, เควสต์ประจำวัน |
| ตะวันตก | แผงตลาด NPC | ยา, วัตถุดิบ, ของใช้ทั่วไป |
| ตะวันออก | **ช่างเครื่องราง** + โต๊ะคราฟต์ | ปลุกเสก, หลอมรวม (GDD 7) |
| ใต้ ริมน้ำ | **ท่าน้ำ + เรือแม่ค้า** | เป็นจุดของ "ตลาดน้ำอรัญญา" (GDD 9.3) และไปรษณีย์ในเกม ชื่อตลาดน้ำจึงมีที่มาจริงในฉาก ข้อเสนอ: ดูราคาและซื้อได้จากทุกที่ แต่การลงขายต้องมาที่เรือ เพื่อให้ผู้เล่นมารวมตัวกันที่ hub |
| กระจายรอบลาน | NPC ผู้ให้เควสต์ | ผู้เฒ่าประจำหมู่บ้านอยู่ใกล้ต้นไทร (เควสต์บทที่ 2) |
| ตะวันออกเฉียงเหนือ | ซุ้มประตูหมู่บ้าน | **ทางออกไปลานศาลเพียงตา** |
| ตะวันตกเฉียงเหนือ | หอสังเกตการณ์ | ใช้บอกทิศจากระยะไกล และเป็นที่ตั้งอีเวนต์ในอนาคต |

**ใช้ asset ซ้ำในบทที่ 1 "คืนหมอกม่วง"** (GDD 8.5)

ฉากราคีบุกหมู่บ้านใช้แผนที่ hub เดียวกัน แต่เป็น instance เดี่ยวตอนกลางคืน และตั้งค่าเกจชำระโซนเป็น 0 (หมอกม่วงเต็มที่) จึงไม่ต้องทำ asset ชุดใหม่ เมื่อจบบทนี้ผู้เล่นจะตื่นขึ้นที่จุดเกิดใน hub ตอนกลางวัน ทำให้ทั้งเนื้อเรื่องใน GDD ("ราคีบุกบ้านร่มไทร") และข้อแนะนำใน concept ("เริ่มที่หน้าลานตลาด") ใช้ได้พร้อมกัน

### 10.9 ลานศาลเพียงตา

อ้างอิง concept ภาพที่ 9

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | **ขนาดของศาลแก้ถูกแล้ว** พื้นศาลยกสูงราวระดับสายตาบนแท่นหินที่มีบันได ตรงกับความหมายของคำว่า "เพียงตา" ส่วนหลังคาที่มีช่อฟ้าคล้ายศาลพระภูมิใช้ได้ เพราะเป็นศาลพื้นบ้าน ไม่ใช่โบสถ์หรือวิหาร องค์ประกอบอื่นที่ใช้ได้: โต๊ะเครื่องเซ่น, ธูปเทียน, โอ่ง, ร่มบ่อสร้าง, เสาศิลาพันผ้า, ลำแสงที่ตกลงบนศาล |
| ❌ ต้องแก้ | **รูปปั้นนั่งสีทองในศาลดูเหมือนพระพุทธรูป** ซึ่งผิดหัวข้อ 9.4 ให้เปลี่ยนเป็น**เศษหยกหัวใจพงไพรที่เรืองแสง `SPIRIT`** วิธีนี้แก้ปัญหาวัฒนธรรม และผูกศาลเข้ากับเนื้อเรื่องไปพร้อมกัน เพราะเป็นที่ที่วิญญาณหยกเลือกผู้เล่น (ดูด้านล่าง) |
| ⚠ ต้องแก้ | **โคมหินบนเสามีหน้าตาเป็นโคมหินญี่ปุ่น** (ทรงหลังคาเจดีย์เล็ก) ให้เปลี่ยนเป็นเสาหัวเม็ดทรงบัวตูม + ตะคันดินเผา (ประทีปน้ำมัน) หรือโคมแขวน |
| ⚠ สี | ผ้าแพรสีชมพูและสีฟ้าอยู่นอกพาเลตต์ ผ้าแพรของจริงมักเป็นชมพู แดง เหลือง เขียว จึงแปลงเป็น `FIRE` / `GOLD` / `JADE` / `CREAM` ส่วน `FIRE` ใช้ได้เพราะลานในรั้วเป็นเขตปลอดภัย (ดูด้านล่าง) |
| ⚠ ความต่าง | ต้นไม้พันผ้าแพรด้านซ้ายหน้าตาเหมือนต้นไทรใน hub ให้เปลี่ยนเป็น**ต้นตะเคียน** ซึ่งเป็นต้นไม้ศักดิ์สิทธิ์ที่คนไทยนิยมผูกผ้าเจ็ดสีจริง ลำต้นตรงกว่าต้นไทรและไม่มีรากอากาศ ทำให้ silhouette ต่างกัน |
| ➕ เพิ่ม | ตุ๊กตาช้างม้าปั้นและพวงมาลัยบนแท่นศาล เป็นของที่อ่านออกได้ทันทีว่าเป็นศาลไทย และยังทำเป็นชิ้น prop เล็กได้ไม่แพง |

**การวางและกติกาของพื้นที่**

| หัวข้อ | สเปก |
|---|---|
| เขตปลอดภัย | ลานที่อยู่ในรั้วหินเป็นเขตที่ไม่มีการต่อสู้ มอนเข้ามาไม่ได้ เพราะราคีเข้าเขตศักดิ์สิทธิ์ไม่ได้ ส่วนมอนเลเวล 1–3 อยู่นอกรั้ว และศาลยังเป็น**จุดผูกการเกิดใหม่จุดที่ 2** สำหรับผู้เล่นช่วงแรก |
| การนำสายตา | ผู้เล่นเข้าจากบันไดทางทิศใต้ (ฝั่งกล้อง) แล้วเห็นศาลอยู่ด้านบนของจอทันที ลำแสงที่ตกบนศาลใช้นำทางตามที่ concept แนะนำ ลำแสงทำเป็นการ์ดแสงแบบ additive (ไม่ใช่ volumetric จริง) และจะจางลงตอนกลางคืน จากนั้นแสงเทียนในศาลรับหน้าที่นำทางแทน |
| ผู้ดูแลศาล (NPC) | ให้เควสต์สายเครื่องรางโบราณ และเป็น**พิธีวิวัฒนาการวิญญาณหยก**: หลังชำระบอสแต่ละโซน ผู้เล่นกลับมาที่ศาลเพื่อเปลี่ยนร่างคู่หู เช่น จากเมล็ดหยกเป็นคันคากหยก ซึ่งเป็นการตีความ "จุดปลดล็อก Spirit Skill" ใน concept |
| จุดเก็บวัตถุดิบ | กอว่านรอบศาลใช้เก็บผงว่าน การเกิดใหม่ของจุดเก็บและของที่ได้คำนวณที่ server |
| ทางเชื่อม | บันไดทางใต้ไปบ้านร่มไทร และสะพานไม้ทางตะวันตกไปทุ่งหญ้าคาลมแล้ง |
| บทที่ 1 "คืนหมอกม่วง" | ราคีบุกบ้านร่มไทร ผู้เล่นหนีมาถึงศาลนี้ แล้วเศษหยกในศาลตื่นขึ้นและเลือกผู้เล่นเป็นวิญญาณหยกคู่กาย instance ของบทนี้จึงครอบคลุมทั้ง hub และศาล (ซิงก์กับ GDD 8.5 แล้ว) |

### 10.10 ทุ่งหญ้าคาลมแล้ง

อ้างอิง concept ภาพที่ 10 พื้นที่ระดับ 3–6 เชื่อมจากลานศาลเพียงตา (ทางตะวันออก) ไปลำธารหิ่งห้อย

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | สีโดยรวม (หญ้าเขียวอมเหลือง `MOSS` สลับหญ้าแห้ง และทางดิน `EARTH`) ไม่ทำให้พื้นเป็นสีทองทั้งจอตามที่เคยเตือนไว้, จอมปลวก, ทางดินคดเคี้ยว, ก้อนหิน, รั้วไม้, เกวียนกับโอ่ง (prop ไทยที่ดี) และกระท่อมเล็ก (ใช้เป็น**เถียงนา**) |
| ⚠ มุมกล้อง | ภาพวาดจากมุมต่ำที่เห็นท้องฟ้า ภูเขาไกล และหมอกขอบฟ้า **ในเกมจะมองไม่เห็นส่วนเหล่านี้** (หัวข้อ 10.1) จึงไม่ต้องลงงานกับฉากหลัง ให้ใช้ distance fog สีหมอกแดดอุ่นที่ขอบบนจอแทน |
| ⚠ Landmark | concept มีต้นตาลราว 7 ต้น ทำให้ไม่มีต้นไหน "โดดเดี่ยว" ตาม brief ให้เหลือ**ต้นตาลหลัก 1 ต้น** ที่สูงและทรงพุ่มใหญ่กว่าต้นอื่นชัดเจน (ประมาณ 1.5 เท่า) และวางห่างจากต้นอื่น ส่วนต้นที่เหลือไว้ริมขอบพื้นที่เป็นกลุ่มเล็ก ๆ |
| ⚠ วัฒนธรรม | เสาหินพันผ้าทางขวามียอดซ้อนชั้นคล้ายเจดีย์ ให้เปลี่ยนเป็น**หลักหินหรือเสาหลักเขต**ที่ยอดเรียบ เพราะพื้นที่นี้มีการต่อสู้รอบ ๆ (หัวข้อ 9.4) ส่วนผ้าที่พันให้ใช้สีในพาเลตต์ |
| ⚠ สี | ผ้าชมพูและฟ้าบนเสาให้แปลงเป็นสีในพาเลตต์ ส่วนท้องฟ้าสีฟ้าไม่ต้องแก้ เพราะไม่ปรากฏในเกมอยู่แล้ว |

**การวางเชิงเกมเพลย์** (ผสาน Gameplay Design ใน concept กับมอนใน GDD 8.3)

| หัวข้อ | สเปก |
|---|---|
| พื้นที่ต่อสู้ | ลานโล่งรัศมีอย่างน้อย 12 เมตรตามข้อแนะนำใน concept กระจาย 3–4 ลานตามทางดิน แต่ละลานมีฝูงมอนของตัวเอง ระยะ aggro ของแต่ละฝูงต้องไม่ทับกัน |
| **จอมปลวก = รังงูเห่าควัน** | ตามความเชื่อไทยที่ว่างูอาศัยในจอมปลวก งูเห่าควันจะโผล่ออกมาเมื่อผู้เล่นเข้าใกล้ จอมปลวกจึงเป็นทั้ง landmark และจุดเกิดของมอน (ตรงกับข้อ 3 ใน concept) และจอมปลวกใหญ่ 1 จอมมีกล่องของซ่อนอยู่ |
| ไก่ป่าเพลิง | อยู่ในพงหญ้าคาเป็นฝูงละ 3–4 ตัว **ขนไก่ป่าเพลิงได้จากการล่า ไม่ใช่จุดเก็บ** (concept เขียนรวมไว้กับจุดเก็บวัตถุดิบ) |
| ผีโขมด | พบมากตอนกลางคืนเหนือทุ่ง ตามคติที่ผีโขมดเป็นดวงไฟลอยตามท้องทุ่ง กลางวันมีน้อย และโคมไฟบนเสาตามทางเป็นจุดอ้างอิงตอนกลางคืน |
| จุดเก็บ | กอว่าน (ผงว่าน) อยู่ใกล้ก้อนหินและร่มไม้ |
| ต้นตาลหลัก | landmark และจุดนำทาง ใต้ต้นเป็นจุดพักที่ไม่มีมอนเกิด |
| ลม | หญ้าและใบตาลขยับด้วย vertex shader ส่วนฝุ่นตามทางเดินเป็น particle ฝั่ง client ที่ไม่มีผลกับการเล่น |
| แสง | ตอนเที่ยงใช้มุมเงยสูงและเงาสั้นตาม concept โดยทิศแสงในแนวราบยังคงมาจากซ้ายบน (หัวข้อ 10.4) |

### 10.11 ลำธารหิ่งห้อย

อ้างอิง concept ภาพที่ 11 พื้นที่ระดับ 5–8 เชื่อมจากทุ่งหญ้าคาไปดงรากไทรพันปี

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | สะพาน (เสาและราวไม้ไผ่แล้ว แต่พื้นสะพานให้เปลี่ยนเป็นฟากไม้ไผ่), น้ำสีหยก, น้ำตกเล็กกับโขดหิน, ต้นไม้ที่แผ่กิ่งคลุมลำธาร, โคมไม้ตามทาง และหิ่งห้อยสีหยก |
| ❌ สี (ซ้ำเป็นครั้งที่ 3) | **ดอกบัวเรืองแสงสีชมพูและม่วง** ม่วงสงวนไว้ให้ราคี ผู้เล่นจะเข้าใจผิดว่าดอกบัวเป็นสิ่งอันตราย ให้เปลี่ยนเป็นบัวขาว `CREAM` ที่แกนเรืองแสง `SPIRIT` ส่วนดอกไม้ม่วงเล็ก ๆ ริมน้ำให้เอาออก |
| ⚠ ซ้ำ | **โคมหินแบบญี่ปุ่น 2 จุดทางขวา** ให้เปลี่ยนตามหัวข้อ 2.1 และหลังคากระท่อมที่งอนแบบจีนให้เปลี่ยนเป็นจั่วไทย |
| ⚠ ปรับ | **กังหันน้ำ** เป็นแบบตะวันตก ให้เปลี่ยนเป็น**หลุก** (กังหันวิดน้ำไม้ไผ่ของภาคเหนือที่ผูกกระบอกไม้ไผ่รอบวง) ซึ่งเป็นภาพที่ไม่ค่อยมีใครใช้ในเกม จึงช่วยให้ฉากมีเอกลักษณ์ |
| ⚠ มุมกล้อง | ดวงจันทร์และท้องฟ้ามองไม่เห็นในเกม แสงจันทร์จึงแปลงเป็นสีของ directional light ตอนกลางคืน ทิศยังคงมาจากซ้ายบน |

**แสงและรอบวัน**

พื้นที่นี้ต้องดู "กลางคืน" ได้ตลอด แต่ทั้งโซนใช้รอบวันเดียวกัน (หัวข้อ 10.4) ทางแก้คือ**ใช้ volume ของ LUT ทั้งพื้นที่**: เรือนยอดที่ปิดทึบทำให้ใต้ต้นไม้เป็นแสงสนธยาเสมอ หิ่งห้อยสีหยกจึงเห็นได้ทุกช่วงเวลา และเมื่อถึงกลางคืนจริงจะมีอีเวนต์ **หิ่งห้อยทอง** (`GOLD`, GDD 8.2) เพิ่มเข้ามา ทำให้กลางคืนจริงยังมีความพิเศษกว่ากลางวัน

**ประสิทธิภาพ** (ฉากนี้มีของเรืองแสงและน้ำเยอะที่สุดในโซน)

| องค์ประกอบ | วิธีทำ |
|---|---|
| ผิวน้ำ | shader เลื่อน UV + normal จาก noise **ไม่ใช้ planar reflection จริง** ส่วนแสงโคมที่สะท้อนในน้ำใช้การ์ด additive วางบนผิวน้ำ |
| หิ่งห้อย | GPU particle ที่บินเป็นฝูงแบบง่าย จำนวนสูงสุด 150 ตัวบน PC และ 60 ตัวบนมือถือ |
| ดอกบัวเรืองแสง | emissive ที่สว่างขึ้นลงเป็นจังหวะผ่าน shader (ไม่ใช่ light) |
| หมอกเหนือน้ำ | plane โปร่งแสง 1–2 ชั้นที่เลื่อน UV ช้า ๆ |
| น้ำตก | mesh ที่เลื่อน UV + particle ฟองน้ำที่ฐาน |
| โคมไฟ | emissive + baked และ dynamic light รวมทั้งฉากไม่เกินงบในหัวข้อ 10.4 |

**การวางเชิงเกมเพลย์**

| หัวข้อ | สเปก |
|---|---|
| เส้นทางหลัก | สะพานไม้ไผ่ตาม concept และผู้เล่นต้องเห็นสะพานถัดไปจากจุดที่ยืนอยู่เสมอ |
| ปริศนาแสงหิ่งห้อย | ฝูงหิ่งห้อยลอยตาม Spirit Flame ของผู้เล่นเมื่อเข้าใกล้ ให้พาหิ่งห้อยไปจุดโคมที่ดับอยู่ 3 ดวง แล้วทางลับจะเปิดไปยังกล่องของที่ซ่อนอยู่ สถานะว่าจุดโคมแล้วกี่ดวงเก็บแยกรายผู้เล่นที่ server ส่วนรางวัลสุ่มที่ server |
| ศัตรู | งูเห่าควันอยู่ริมน้ำช่วงต้น (เลเวล 5–8) นางไม้หลงราคีอยู่ปลายลำธารก่อนเข้าดงรากไทร ซึ่งตรงกับเควสต์บทที่ 3 "เสียงร้องจากลำธาร" และผีโขมดออกตอนกลางคืน |
| จุดเก็บ | กอว่านริมน้ำ เก็บผงว่านได้มากขึ้นช่วงอีเวนต์หิ่งห้อยทอง (GDD 8.2) |
| "จุดค้นหา Spirit Flame" | **ข้อเสนอ**: ซ่อน **ดวงวิญญาณหลงทาง** ไว้ตามจุดลับ เก็บครบแล้วปลดล็อกสีของ Spirit Flame (ไฟ, มืด, ทอง ตาม LUT ในหัวข้อ 8.2) ซึ่งเป็นแค่การเปลี่ยนรูปลักษณ์ ไม่มีผลกับพลัง (ดูหัวข้อ 13) |
| ทางเชื่อม | ปลายลำธารทางทิศเหนือขึ้นไปดงรากไทรพันปี |

### 10.12 ดงรากไทรพันปี

อ้างอิง concept ภาพที่ 12 พื้นที่ระดับ 8–11 เชื่อมจากลำธารหิ่งห้อย (ทางใต้) ไปหุบราคีม่วง และมีทางเข้าดันเจี้ยนห้องรากไทร ต้นไทรต้นนี้คือต้นที่นาคาไทรมูลผสานร่างอยู่ (GDD 8.6) จึงเป็นคนละต้นกับต้นไทรกลางหมู่บ้านร่มไทร

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | **สีดีที่สุดในชุด** (`BARK`, `FOREST_DEEP`, `MOSS` และลำแสง `CREAM`) รากยักษ์ที่เป็นสะพาน, บันไดหินขึ้นลงหลายระดับ, ราวไม้ผูกเชือก, ซุ้มประตูซากโบราณที่ฝังในราก, รากอากาศ, น้ำตกเล็ก และหมอกที่ปิดก้นหุบ |
| ✔ ใช้ได้ | **วงแสงหยกบนแท่น 3 จุด** ลายก้นหอยเข้ากับหัวข้อ 9.3 นำไปใช้เป็นวงวาร์ประหว่างชั้น (ดูด้านล่าง) |
| ❌ วัฒนธรรม (ซ้ำเป็นครั้งที่ 2) | **รูปนั่งสีทองเรืองแสงในศาลบนรากดูเหมือนพระพุทธรูป** ให้เปลี่ยนเป็น**รูปสลักหัวนาคหินที่มีรากไทรพัน** ซึ่งปูทางไปสู่บอสของโซน และไม่ซ้ำกับเศษหยกในลานศาลเพียงตา ส่วนลายที่สลักเหนือประตูศาลต้องเป็นลายก้นหอยหรือกนก ห้ามเป็นอักขระ |
| ⚠ ซ้ำ (ครั้งที่ 4) | **เสาหินที่มียอดเป็นหลังคาเล็กและมีไฟอยู่ข้างใน** เป็นโคมหินญี่ปุ่น ให้เปลี่ยนตามหัวข้อ 2.1 เป็นเสาหัวเม็ดทรงบัวตูมที่วางตะคันไว้บนยอด |
| ⚠ สี (ซ้ำ) | ดอกไม้สีชมพูทางซ้ายและดอกไม้ม่วงริมน้ำตกให้เอาออก ถ้าต้องการจุดสีให้ใช้เห็ดเรืองแสง `SPIRIT` ตามที่ brief เขียนไว้ ส่วน "หมอกเขียวอมฟ้า" ให้ใช้ `JADE_DEEP` เพราะไม่มีสีฟ้าในพาเลตต์ |
| ⚠ ชื่อสี | "ROOT GREEN" และ "LIGHT RAY" ไม่มีในพาเลตต์ ให้ใช้ `MOSS` / `FOREST` และ `CREAM` (การ์ดลำแสงแบบ additive, E-16) แทน |
| ⚠ เกมเพลย์ | **"กระโดดข้ามรากไม้"** ขัดกับหัวข้อ 13 ข้อ 4 (ผู้เล่นกระโดดไม่ได้) ให้แทนด้วยจุดไต่และสะพานรากที่ฟื้นได้ ส่วน **"กล้อง Orthographic 45°"** ใช้กล้องตามหัวข้อ 10.1 เหมือนพื้นที่อื่น |
| ⚠ ไอเทม | **"เกล็ดหยกนาค" ให้เก็บในพื้นที่นี้ไม่ได้** เพราะใน GDD 8.6 เป็นรางวัลเคลียร์บอสครั้งแรกที่ใช้วิวัฒนาการวิญญาณหยก ถ้าหาได้ในพื้นที่เปิด ลำดับการวิวัฒนาการจะพัง (ดูข้อเสนอด้านล่าง) |

**เลย์เอาต์แนวตั้งกับกล้อง**

กล้องก้ม 35° และ yaw ล็อก ถ้าวางชั้นซ้อนกันตรง ๆ ชั้นบนจะบังชั้นล่าง จึงใช้กฎดังนี้

| กฎ | สเปก |
|---|---|
| **ขั้นบันไดไปทางทิศเหนือ** | ยิ่งสูงยิ่งอยู่ทางเหนือ (ไกลกล้อง) ชั้น 1 อยู่ใต้สุดและชั้น 3 อยู่ติดลำต้นทางเหนือสุด หน้าผาของแต่ละชั้นจึงหันเข้าหากล้อง ชั้นบนไม่บังชั้นล่าง และผู้เล่นเห็นปลายทางของชั้นถัดไปอยู่ด้านบนจอ ซึ่ง concept วางแบบนี้อยู่แล้ว |
| ความสูงต่อชั้น | 3–4 เมตร จุดลงของบันไดหรือจุดไต่ต้องอยู่ในครึ่งบนของจอเมื่อยืนที่จุดเริ่ม คำนวณได้จาก `0.82 × ความสูง + 0.57 × ระยะไปทางเหนือ ≤ 4.5 เมตร` (ที่ pixel scale ×3) ความยิ่งใหญ่ให้มาจากลำต้นและรากที่สูงเลยขอบจอ ไม่ใช่จากความสูงที่เดินได้ |
| สะพานที่ข้ามทางด้านล่าง | กว้างไม่เกิน 3 เมตร ใต้สะพานห้ามมีจุดเกิดมอน จุดเก็บ หรือลานต่อสู้ และใช้การจางหายตามหัวข้อ 10.4 |
| ลำต้นไทร | อยู่ขอบทิศเหนือของพื้นที่ เห็นแค่โคนต้นกับรากที่แผ่ออก ส่วนเรือนยอดอยู่นอกจอ (หัวข้อ 10.1) ทำเป็นชิ้นใหญ่ผสมกับ kit ราก (E-05) ไม่นับเป็น prop landmark 15k tris ในหัวข้อ 10.2 แต่นับรวมในงบทั้งจอ |
| ก้นหุบ | หมอกแบบอิงความสูง (height fog) สี `JADE_DEEP` ปิดทุกอย่างที่ต่ำกว่าชั้น 1 จึงไม่ต้องทำฉากด้านล่าง |
| ขอบทาง | **ไม่มีการตกจากที่สูง** ทุกขอบมีราวหรือ collision ส่วนแรงผลักของสกิลจะหยุดที่ขอบ |

**การเคลื่อนที่ระหว่างชั้น** (แทนการกระโดดใน concept)

| วิธี | ทำงานอย่างไร | สถานะเก็บที่ไหน |
|---|---|---|
| บันไดและทางลาดราก | เส้นทางหลัก เปิดเสมอ | – |
| จุดไต่ราก | ยืนใกล้แล้วกดปุ่มโต้ตอบ ตัวละครไต่ขึ้นตามเส้นทางที่กำหนดไว้ใน 1–1.5 วิ (ท่าไต่ ทิศ N) ผนังที่ไต่ได้ต้องหันเข้าหากล้องเพื่อให้เห็นตัวละคร | – |
| โรยตัวตามรากอากาศ | ทางลัดขาลงจากชั้นบนลงชั้นล่าง ใช้ได้ทางเดียว ขาลงจึงเร็ว ขาขึ้นต้องเดินทางหลักหรือใช้วงวาร์ป | – |
| **สะพานรากที่ฟื้นได้** (ปริศนาสั้น ๆ ตาม GDD 8.2) | รากที่เหี่ยวเพราะราคีจะฟื้นเป็นสะพานเมื่อชำระศิลาราคีที่อยู่ใกล้ แล้วกลับไปเหี่ยวเมื่อศิลาราคีเกิดใหม่ ใช้เปิดทางไปกล่องของหรือจุดเก็บ **ห้ามใช้กับเส้นทางหลัก** | แชร์ทั้ง channel ใน room state เพราะทุกคนเห็นสะพานเหมือนกัน จึงไม่มีภาพผู้เล่นคนอื่นเดินบนอากาศ |
| **วงวาร์ปหยก** (วงแสงใน concept) | ยืนในวง 3 วิเพื่อปลุกครั้งแรก หลังจากนั้นวาร์ประหว่างวงที่ปลุกแล้วได้ ซึ่งตรงกับ "ใช้รากไม้เป็นเส้นทางลัดระหว่างชั้น" ใน concept | แยกรายผู้เล่นใน DB ตัววงเห็นเหมือนกันทุกคน ต่างกันแค่ว่าใช้ได้หรือไม่ |

**หมายเหตุเทคนิค (ฝั่ง server)**: พื้นที่นี้เป็นที่แรกที่มีพื้นซ้อนกันหลายชั้น

- ตำแหน่งผู้เล่นและมอนต้องเป็น 3 มิติ และ server ใช้ navmesh ที่รองรับหลายชั้น (bake จากเรขาคณิตของฉากใน `/tools` แล้วให้ client ใช้ไฟล์เดียวกันสำหรับ prediction)
- การตัดสินว่าโดนหรือไม่ต้องเช็กความต่างความสูงด้วย เช่น `|Δy| ≤ 1.5 เมตร` เก็บเป็นค่าคงที่ใน `/shared` เพื่อไม่ให้สกิลบนชั้น 2 โดนผู้เล่นชั้น 1 ที่อยู่ข้างใต้
- **พื้นเตือนต้องฉายลงเฉพาะชั้นเดียวกับผู้ร่าย** ถ้า decal ไปโผล่บนชั้นล่างด้วย ภาพจะไม่ตรงกับผลที่ server คำนวณ
- จุดไต่และการโรยตัวเป็น off-mesh link: client ส่ง intent "ใช้ link X" แล้ว server ตรวจระยะ (ไม่เกิน 1.5 เมตร) และเลื่อนตัวละครตามเส้นทางในเวลาที่กำหนด ระหว่างนั้นโดนตีได้แต่ไม่ถูกขัด และทำอย่างอื่นไม่ได้
- มอนใช้ link ไม่ได้ ยกเว้นลิงลมม่วงที่ GDD 8.3 กำหนดให้กระโดดข้ามรากไม้ และมอนทุกตัวผูก leash ไว้กับชั้นของตัวเอง
- ควรพิสูจน์ navmesh หลายชั้นตั้งแต่ Tech Spike (F-08) เพราะถ้าทำไม่ได้ต้องเปลี่ยนเลย์เอาต์ของพื้นที่นี้

**การวางเชิงเกมเพลย์** (ผสาน Vertical Level Design ใน concept กับ GDD 8.2, 8.3 และ 8.5)

| ชั้น | สิ่งที่อยู่ | ศัตรู |
|---|---|---|
| ชั้น 1 โคนต้นไทร | ทางเข้าจากลำธาร, ลานซากโบราณ, **ประตูรากที่โคนต้น = ทางเข้าดันเจี้ยนห้องรากไทร** (ปิดด้วยม่านราคีจนกว่าผู้เล่นจะชำระแท่นราคีในหุบราคีม่วง หัวข้อ 10.13) | นางไม้หลงราคี และอีลิตคชสีห์น้อยคลั่งในลานซากโบราณ ซึ่งเป็นลานโล่งยาวพอให้พุ่งชนเป็นเส้นตรง |
| ชั้น 2 ทางเดินราก | สะพานราก, ลานบนรากที่กว้างพอต่อสู้ (รัศมีอย่างน้อย 8 เมตร), สะพานรากที่ฟื้นได้, จุดโรยตัวลงชั้น 1 | ลิงลมม่วงที่โดดข้ามชั้นลงมาซุ่มโจมตี |
| ชั้น 3 ยอดราก | **ศาลวิญญาณ** (รูปสลักหัวนาค) เป็นจุดผูกการเกิดใหม่จุดที่ 3 และวงวาร์ปหยกวงหลัก, จุดชมวิว, **ม่านราคีทางทิศเหนือ = ทางเข้าหุบราคีม่วง** | ลิงลมม่วง (ยักษ์ปักหลั่นย้ายไปเฝ้าแท่นราคีในหุบ ดูหัวข้อ 10.13) |

| หัวข้อ | สเปก |
|---|---|
| ลำดับเนื้อเรื่อง | บทที่ 4 "รากที่ร่ำไห้" เริ่มที่ศาลวิญญาณ: วิญญาณหยกรับรู้ความเจ็บปวดของนาค ผู้เล่นจึงข้ามม่านราคีไปหาต้นตอที่หุบราคีม่วง ชำระแท่นราคีซึ่งเป็นผนึกของประตูราก แล้วกลับลงมาที่ประตูรากชั้น 1 เพื่อเข้าห้องรากไทรในบทที่ 5 อีลิตคชสีห์น้อยในพื้นที่นี้และยักษ์ปักหลั่นในหุบช่วยสอนระบบปาร์ตี้ตามที่บทที่ 4 กำหนด |
| จุดชมวิว | กดโต้ตอบแล้วกล้องฝั่ง client แพนไปทางเหนือให้เห็นหุบราคีม่วงกับหมอกม่วงชั่วครู่ เป็นข้อยกเว้นเรื่องท้องฟ้าแบบเดียวกับ cutscene (หัวข้อ 10.1) |
| ม่านราคีและประตูราก | ทุกคนเห็นเหมือนกัน แต่ server เช็ก flag เควสต์รายผู้เล่นว่าผ่านได้หรือไม่ ผู้ที่ยังไม่ถึงจะเห็นคนอื่นเดินทะลุม่าน ซึ่งเข้ากับการเป็นม่านเวท |
| จุดเก็บ | **ใบไทรเงิน** เก็บได้จากกิ่งไทรบนชั้น 2–3 (เพิ่มจากที่ดรอปจากนางไม้หลงราคี) และเห็ดเรืองแสงเป็นของประดับเท่านั้น |
| "เกล็ดหยกนาค" ใน concept | **ข้อเสนอ**: เปลี่ยนเป็น**คราบนาค** ซึ่งเป็นไอเทมเควสต์ของบทที่ 4 ที่ซื้อขายไม่ได้ และเป็นร่องรอยว่ามีนาคอยู่ใต้ต้นไทร ส่วนเกล็ดหยกนาคยังได้จากบอสเท่านั้น (ดูหัวข้อ 13) |
| แสง | ลำแสงเป็นการ์ด additive (E-16) ตกเป็นจุดบนลานต่อสู้และจุดหมายของแต่ละชั้น เพื่อใช้นำทางแบบเดียวกับลานศาลเพียงตา |

### 10.13 หุบราคีม่วง

อ้างอิง concept ภาพที่ 13 พื้นที่ระดับ 10–12 อยู่ทางเหนือของดงรากไทรพันปี เข้าทางม่านราคีบนชั้น 3 เป็นพื้นที่ที่เกจชำระโซนมีผลมากที่สุด (GDD 8.2, 8.4)

**ผลตรวจ concept**

| ผล | รายการ |
|---|---|
| ✔ ใช้ได้ | ต้นไม้ตายที่บิดเบี้ยว, ซุ้มประตูซากโบราณ, สะพานไม้ข้ามเหวหมอก, **แท่นราคีบนลานยกสูงที่มีผลึกกลางวง** (เป็นจุดหมายที่เห็นชัด), ทางหินที่สว่างกว่าพื้นรอบข้างจนอ่านเส้นทางออก และหมอกที่ปิดเหว |
| ✔ ใช้ได้ | **สัญลักษณ์ราคีบนซุ้มประตู** (ทรงข้าวหลามตัดมีตา) ให้ใช้เป็น**ตราราคีกลาง**ชิ้นเดียวทั้งเกม ทั้งบนฉาก ไอคอนดีบัฟราคีสะสม และ UI โดยต้องไม่คล้ายยันต์หรืออักขระจริง (หัวข้อ 9.4) |
| ❌ สี (ซ้ำจากภาพที่ 7) | **ยังเป็นม่วงสว่างทั้งจอ** ทั้งหมอกสีลาเวนเดอร์ หินอมม่วง และพุ่มไม้ม่วง ส่วนผลึก `CURSE` มีราว 20 จุดซึ่งเกิน 15% ของจอ ผลคือศัตรูที่ติดราคีและพื้นเตือนจะกลืนไปกับฉาก แก้ตามด้านล่าง |
| ⚠ ชื่อสี | "DARK VIOLET" และ "CRYSTAL GLOW" ไม่มีในพาเลตต์ ให้ใช้ `PURPLE_DEEP` และ `CURSE` ส่วนแสงรอบทิศ "ม่วงเข้มและน้ำเงินดำ" ให้ใช้ `INK` + `PURPLE_DEEP` เพราะไม่มีสีน้ำเงิน |
| ⚠ เกมเพลย์ | **"ทำลายผลึกราคี"** ให้เปลี่ยนคำเป็น**ชำระ** ตามเสาหลักข้อ 1 "ชำระ ไม่ใช่ทำลาย" และผลึกพวกนี้คือศิลาราคีใน GDD 8.4 (ยืนนิ่ง 3 วิ) |
| ⚠ เกมเพลย์ | **ห้องบอสไม่ได้อยู่ในหุบนี้** ทางเข้าห้องรากไทรอยู่ที่ประตูรากในดงรากไทรชั้น 1 ตาม GDD 8.2 (หัวข้อ 10.12) แท่นราคีในหุบจึงเป็น "ผนึก" ที่เปิดประตูนั้น และหมอกจะหนาขึ้นเมื่อเข้าใกล้แท่น ไม่ใช่เมื่อเข้าใกล้ห้องบอส |
| ⚠ มุมกล้อง | ท้องฟ้าและภูเขาไกลด้านบนมองไม่เห็นในเกม (หัวข้อ 10.1) |

**ความอ่านง่าย: ลำดับความสว่าง** (หัวใจของพื้นที่นี้)

ให้ตรวจโดยแปลงภาพเป็นขาวดำ ลำดับต้องเป็นดังนี้ จากมืดไปสว่าง

| ลำดับ | สิ่งที่อยู่ในระดับนี้ | สี |
|---|---|---|
| 1 มืดสุด | พื้น, หน้าผา, หมอกในเหว, ต้นไม้ตาย | `INK`, `PURPLE_DEEP`, `BARK` |
| 2 | ทางเดินหลัก, ซากกำแพง | `STONE` (ไม่อมม่วง ให้ LUT ของพื้นที่เป็นตัวย้อมแทน) |
| 3 | ผลึกประดับ | ตัวผลึก `PURPLE_DEEP` ส่วนปลายเป็น `CURSE` ไม่เรืองและไม่ bloom จอละไม่เกิน 12 ชิ้น |
| 4 | ศิลาราคีที่ชำระได้, ตะคันนำทาง | `CURSE` เรืองเป็นจังหวะ + decal หมอก / เปลวไฟ `GOLD` แกน `CREAM` (ไม่ใช้ `FIRE` เพราะสงวนไว้ให้ความหมายว่าอันตราย) |
| 5 สว่างสุด | ศัตรู, พื้นเตือน, ผู้เล่น | ตามหัวข้อ 3 และ 8 พื้นเตือนวาดทับทุกอย่างเสมอ |

รวมแล้ว `CURSE` ที่สว่างต้องไม่เกิน 15% ของจอ และการนำทางให้ใช้**ตะคันสีทองบอกเส้นทาง ส่วนผลึกบอกอันตรายและเป้าหมาย** เพราะผลึกมีอยู่ทั่วไปจนนำทางไม่ได้ ซึ่งต่างจากข้อแนะนำใน concept

**หมอกราคี** (Cursed Fog ใน concept) ใช้สถานะ **ราคีสะสม** ที่มีอยู่แล้วใน GDD 5.3 (และใช้ในท่า "ราคีสะสมหมู่" ของบอส GDD 8.6) ไม่ต้องสร้างกลไกใหม่

| หัวข้อ | สเปก |
|---|---|
| ที่มา | ศิลาราคีแต่ละก้อนในหุบปล่อยหมอกรัศมี 6 เมตร (ในพื้นที่อื่นเป็นแค่ decal 3 เมตรที่ไม่มีผล) |
| ผล | อยู่ในหมอกครบทุก 3 วิได้ราคีสะสม +1 ชั้น ครบ 5 ชั้นเสีย HP 2% ต่อวิ (ตามกติกาเดิม) ผู้เล่นจึงอยู่ในหมอกได้ราว 15 วิก่อนเริ่มเสียเลือด ล้างได้ด้วยวิญญาณหยกหรือปัดเป่าราคี และระหว่างนั้นได้ดาเมจเพิ่มชั้นละ 6% จึงเป็นการแลกความเสี่ยงกับผลตอบแทน |
| ชำระ | ชำระศิลาราคีแล้วหมอกรอบก้อนนั้นหายไปจนกว่าศิลาจะเกิดใหม่ สถานะแชร์ทั้ง channel ใน room state |
| ภาพต้องตรงกับ server | รัศมีของหมอกที่เห็นต้องเท่ากับรัศมีที่ server ใช้ เก็บเป็นค่าเดียวกันใน `/shared` ขอบหมอกเป็นเส้น `CURSE` ที่**สว่างขึ้นลงช้า ๆ** แยกจากพื้นเตือนของศัตรูที่ขอบ `CREAM` กะพริบเร็ว |
| ความสูง | หมอกเป็น plane ต่ำไม่เกิน 0.5 เมตร วาดก่อนสไปรต์และพื้นเตือน จึงไม่บังตัวละครหรือพื้นเตือน |
| เส้นทางหลัก | ต้องเดินผ่านหมอกได้ภายในไม่เกิน 10 วิ หรือมีทางอ้อม ผู้เล่นที่ไม่มีคนในทีมล้างราคีได้จะไม่ติดอยู่ |
| ห้าม | VFX บรรยากาศที่เป็นวงหรือคลื่นบนพื้น ("คลื่นพลังสีม่วงตามพื้นดิน" ใน concept) เพราะหน้าตาจะเหมือนพื้นเตือน ให้ใช้ละอองลอยในอากาศกับหมอกที่เลื่อน UV แทน |

**ราคีกับเกจชำระโซน**: asset ทุกชิ้นในหุบวาดด้วยสีปกติ (`STONE`, `EARTH`, `MOSS`, `BARK`) แล้วให้ LUT volume ของพื้นที่ (E-20) กับ shader ราคี (E-09) ย้อมเป็นม่วง ตามหัวข้อ 10.4 เมื่อเกิดอีเวนต์ "ไทรผลิใบ" หุบจึงกลับเป็นสีเขียวได้โดยไม่ต้องมี asset สองชุด

**การวางเชิงเกมเพลย์** (ผสาน concept กับ GDD 8.2–8.5)

| หัวข้อ | สเปก |
|---|---|
| Landmark | **ไทรตาย** ต้นไทรโบราณที่ตายเพราะราคี อยู่กลางหุบบนลานโล่งเส้นผ่านศูนย์กลางอย่างน้อย 40 เมตร ลานนี้ใช้เป็น**จุดเกิดบอสโลกวิญญาณไทรยักษ์** (หัวข้อ 7.6) ซึ่งต้องรองรับผู้เล่นได้ถึง 80 คน ระหว่างอีเวนต์ "ไทรผลิใบ" ต้นไทรตายจะแตกใบด้วยกลุ่ม leaf card ที่ซ่อนไว้และเปิดตามค่าเกจ ตรงกับชื่ออีเวนต์พอดี |
| ศัตรู | ลิงลมม่วงอยู่บนต้นไม้ตาย (เลเวล 9–12) และ**ข้อเสนอ**: เพิ่ม**ผีโขมดราคี**และ**งูเห่าราคี** (เลเวล 10–12) ซึ่งใช้สไปรต์เดิมที่สลับสีด้วย LUT (F-04) ไม่ต้องวาดใหม่ |
| "เก็บแก่นโขมดและฟันงู" ใน concept | สองอย่างนี้เป็นของดรอปจากมอน ไม่ใช่จุดเก็บ (GDD 8.3) จึงได้จากร่างราคีของมอนตามข้อเสนอด้านบน |
| แท่นราคี (Guardian) | ปลายทางของหุบทางทิศเหนือ หมอกหนาที่สุด **อีลิตยักษ์ปักหลั่น** (เลเวล 12) เฝ้าอยู่ ซึ่งพฤติกรรม "ปักหลักตรงกลาง สร้างวงควัน และเรียกลูกน้อง" ใน GDD 8.3 เข้ากับการเป็นผู้เฝ้าแท่นพอดี ลานรอบแท่นต้องราบและมีรัศมีอย่างน้อย 10 เมตร |
| ชำระแท่น | ขั้นตอนสุดท้ายของบทที่ 4 เก็บเป็น flag เควสต์รายผู้เล่น ผลคือม่านราคีที่ประตูรากในดงรากไทรเปิดให้ผู้เล่นคนนั้น ส่วนภาพของแท่นยังเป็นราคีเหมือนเดิมสำหรับทุกคน และจะสะอาดเฉพาะช่วง "ไทรผลิใบ" |
| ทางกลับ | ชำระแท่นแล้วจะได้วงวาร์ปหยกที่แท่น ซึ่งเชื่อมกับวงในดงรากไทร (หัวข้อ 10.12) ผู้เล่นจึงไม่ต้องเดินย้อนกลับผ่านหุบ |
| สะพานข้ามเหว | ใช้กฎ "ไม่มีการตก" ตามหัวข้อ 10.12 และบนสะพานห้ามมีจุดเกิดมอน |

**ประสิทธิภาพ**

| องค์ประกอบ | วิธีทำ |
|---|---|
| ผลึก | thin instances ใช้ emissive ไม่ใช้ light และ bloom ทำงานเฉพาะศิลาราคีที่ชำระได้ (ตั้ง threshold ใน LUT ของพื้นที่) |
| หมอก | plane ซ้อนไม่เกิน 2 ชั้นที่จุดเดียวกัน บนมือถือเหลือ 1 ชั้น |

## 11. Pipeline การผลิตและ export

### 11.1 Pipeline ตัวละครแนะนำ: ปั้น 3D แล้ว render เป็นพิกเซล

concept ระบุว่า "2.5D Stylized 3D / Chibi" แต่เกมใช้สไปรต์พิกเซล ทางเชื่อมสองอย่างนี้คือ **ปั้นโมเดล 3D แล้ว pre-render เป็นสไปรต์** (เทคนิคเดียวกับที่ใช้ในเกมพิกเซลหลายเกม)

```
model sheet (2D) → ปั้น 3D chibi + rig → animate
   → render ที่ 64px ด้วย toon shader, ปิด AA, กล้อง 3/4 แบบ orthographic
   → quantize ให้เหลือพาเลตต์ 15 สี → ศิลปินเก็บงานพิกเซลด้วยมือ (หน้า, outline)
   → export atlas
```

| ข้อดี | ข้อเสีย |
|---|---|
| หน้าตาและชุดคงที่ทุกมุมและทุกท่า ตรงกับข้อเสนอใน concept ที่ให้ "ล็อกโมเดลก่อน" | ต้องลงทุนทำ rig และ toon shader ช่วงแรก |
| ชุดแต่งตัวที่ขายในร้านทำได้ถูก แค่เปลี่ยน mesh แล้ว render ใหม่ | ยังต้องมีศิลปินเก็บงานทุกเฟรมสำคัญ |
| เพิ่มทิศเป็น 8 ทิศในอนาคตได้ด้วยการ render ใหม่ | |

มอนเล็ก, VFX และ UI **วาดด้วยมือใน Aseprite** เพราะเร็วกว่า

### 11.2 ไฟล์และการตั้งชื่อ

```
/art/source/<category>/<name>.aseprite     ไฟล์ต้นฉบับ (1 ไฟล์ต่อ 1 หน่วย ใช้ tag ต่อท่า)
/art/source/<category>/<name>.blend        โมเดล 3D (ถ้าใช้ pipeline 3D → พิกเซล)
/art/palette/aranya-15.gpl                 พาเลตต์ (แหล่งเดียว)
/art/reference/concept/ref_<NN>_<name>.png ภาพ concept อ้างอิง (ห้ามใช้เป็น asset และ CI ตรวจพาเลตต์ต้องข้าม)
/client/public/assets/<zone>/...           ไฟล์ที่ export แล้ว (สร้างจาก /tools ห้ามแก้ด้วยมือ)
```

| ชิ้นงาน | รูปแบบชื่อ | ตัวอย่าง |
|---|---|---|
| ตัวละคร | `chr_<class>_<layer>` | `chr_swordsman_body`, `chr_swordsman_outfit_starter` |
| มอน | `mob_<zone>_<name>` | `mob_z01_firefowl` |
| บอส | `boss_<zone>_<name>` | `boss_z01_naga_saimun` |
| VFX | `vfx_<name>` (indexed) | `vfx_slash`, `vfx_impact` |
| UI | `ui_<group>_<name>` | `ui_frame_panel`, `ui_icon_skill_spirit_slash` |
| ไอคอนไอเทม | `item_<group>_<name>` | `item_talisman_takrut`, `item_mat_wan_powder` |
| ฉาก 3D | `env_<zone>_<name>` | `env_z01_ruin_wall_corner`, `env_z01_banyan_root_curve` |
| Tag ของท่าใน Aseprite | `<anim>_<dir>` | `run_S`, `attack1_E`, `idle_N` |

### 11.3 การตั้งค่า export

| หัวข้อ | ค่า |
|---|---|
| Atlas | Aseprite CLI → JSON + PNG, padding 2px + **extrude ขอบ 1px** (กันเส้นขอบรั่ว) |
| การบีบอัดสไปรต์ | **PNG หรือ WebP แบบ lossless** หรือ KTX2 แบบ UASTC **ห้ามใช้ ETC1S หรือ JPEG** เพราะสีจะเพี้ยนและหลุดพาเลตต์ |
| สไปรต์ indexed (VFX, บอสที่ต้อง swap สี) | เก็บเป็น texture R8 แบบไม่บีบอัด + LUT 16×N |
| Texture ฉาก 3D | KTX2 (ETC1S ได้ เพราะ engine ลงแสงทับอยู่แล้ว), ขนาดสูงสุด 512² |
| Sampling | `NEAREST` สำหรับสไปรต์และ UI ส่วน texture ฉากใช้ `NEAREST` + mipmap แบบ nearest |
| Alpha | สไปรต์ใช้ alpha แค่ 0 หรือ 255 ส่วน VFX ใช้ alpha ได้ทุกระดับ |
