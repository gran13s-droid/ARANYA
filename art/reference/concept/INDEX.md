## การเพิ่มภาพใหม่

1. ตั้งชื่อ `ref_<NN>_<subject>.png` โดยใช้เลขถัดไป (ไม่ใช้เลขซ้ำ และไม่เปลี่ยนเลขของภาพเดิม เพราะเอกสารอ้างอิงตามเลข)
2. เก็บคำอธิบายที่แนบมากับภาพไว้ใน `briefs/` ตามที่ได้รับ
3. เพิ่มแถวในตารางนี้ หลังจากบันทึกผลตรวจใน Art Bible แล้ว
4. ถ้าเป็น concept ฉบับแก้ของภาพเดิม ให้ใช้เลขใหม่และต่อท้าย `_v2`, `_v3` เช่น ภาพที่ 3 กับ 17

## ทดลองใส่ภาพที่ 20 ในเกม

ภาพที่ 20 เป็นภาพวาด ไม่ใช่พิกเซลอาร์ต แต่ pipeline แปลงเป็นพิกเซล 64×64 ให้ได้เพื่อดูในเกมช่วงต้นแบบ (`tools/src/importPainted.ts`)
1. คัดลอก PNG กับ JSON ไปที่ `art/source/characters/`
2. ตั้งชื่อไฟล์ทั้งสองให้ตรงกัน
3. แก้ `meta.image` ใน JSON ให้ตรงกับชื่อ PNG
4. รัน `pnpm assets`

ถ้าจะให้เป็นตัวละครที่เกมใช้ ให้ตั้งชื่อเป็น `chr_placeholder` หรือแก้ `CHARACTER_ATLAS` ใน `client/src/main.ts`

## หมายเหตุ

- ภาพทั้งหมดรวมประมาณ 44MB ถ้าเริ่มใช้ git ให้เก็บ `art/reference/**/*.png` ด้วย Git LFS
- สคริปต์ตรวจอาร์ตใน CI (F-02) ต้องข้ามโฟลเดอร์นี้ เพราะภาพ concept ไม่ได้อยู่ในพาเลตต์ 15 สี
