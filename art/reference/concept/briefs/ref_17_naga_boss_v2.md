Naga Boss – พญานาคแห่งรากไทร
Legendary Boss
 2.5D Stylized 3D


คอนเซปต์: ผู้พิทักษ์แห่งรากไทรโบราณที่ถูกพลังราคีม่วงกัดกิน หลับใหลอยู่ใต้ห้องรากไทรมานับพันปี เมื่อผู้เล่นทำลายผนึกทั้ง 4 แท่น พญานาคจะตื่นขึ้นและปลดปล่อยพลังที่แท้จริง
รูปแบบการต่อสู้ 3 Phase










Phase 1 – ร่างพญานาคป้องกัน
Defensive Form
- โจมตีด้วยลำตัวและเขี้ยว
- พุ่งเข้าหาผู้เล่น
- ใช้หางกวาดพื้นที่
- ขดตัวป้องกันการโจมตี













Phase 2 – ร่างพญานาคคำสาป
Corrupted Form
- ปล่อยคลื่นคำสาปสีม่วง
- ยิงลูกบอลพลังงาน
- สร้างหมอกพิษรอบสนาม
- เรียกผลึกราคีจากพื้น













Phase 3 – ร่างพญานาคเต็มพลัง
True Form / Ultimate
- ปลดปล่อยพลังแห่งรากไทร
- สร้างพายุพลังวิญญาณ
- โจมตีด้วยลำแสงพญานาค
- ใช้ท่าไม้ตายทำลายพื้นที่วงกว้าง



Boss Skill Set
Skill	รายละเอียด
Tail Sweep	กวาดหางโจมตีรอบตัว
Fang Strike	พุ่งกัดผู้เล่น
Naga Rush	พุ่งทะลุสนาม
Curse Wave	คลื่นคำสาปสีม่วง
Spirit Orb	ลูกบอลพลังงาน
Poison Mist	หมอกพิษ
Naga Storm	พายุพลังนาค
Ancient Wrath	ท่าไม้ตาย

Gameplay Mechanic: Four Root Altars
แท่นรากทั้ง 4 ในห้องบอสสามารถใช้เป็นกลไกหลักของการต่อสู้ได้
1. ผู้เล่นทำลายผนึกเพื่อปลดล็อกการต่อสู้
2. Phase 1 บอสใช้พลังทางกายภาพ
3. Phase 2 บอสทำลายผนึกและปล่อยคำสาป
4. Phase 3 บอสปลดปล่อยพลังเต็มรูปแบบ
Visual Direction
- เกล็ด: Jade Green / Dark Emerald
- เกราะ: Antique Gold ลวดลายไทย
- ดวงตา: Crimson / Purple Glow
- พลังคำสาป: Violet / Magenta
- พลังแท้จริง: Jade Cyan / Gold
- รูปร่าง: ลำตัวยาวขดเป็นวง มีเขาและแผงคอ
ข้อแนะนำ: ควรให้ Phase 3 เปลี่ยน Silhouette ของบอสอย่างชัดเจน เช่น แผงคอขยาย เขาทองเรืองแสง และมีพลังวิญญาณสีหยกปะทะกับคำสาปสีม่วง เพื่อให้ผู้เล่นรู้สึกว่าเป็นการเผชิญหน้ากับพญานาคตัวจริง ไม่ใช่แค่บอสตัวเดิมที่มีพลังโจมตีแรงขึ้นครับ
